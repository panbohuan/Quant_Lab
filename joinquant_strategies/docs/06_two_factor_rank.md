# 策略 6：双因子组合选股（动量 + 市值，排序打分法）

> 策略类型：双因子选股 ｜ 难度：★★★☆☆ ｜ 前置知识：策略2/3/4、pandas 基础

## 一、核心思路：为什么要做"多因子"

单因子策略（策略2~5）的问题在于**风格过于集中**：
- 只买动量 → 市场风格急转时暴跌；
- 只买小市值 → 大盘蓝筹行情时长期跑输；
- 只买低估值 → 成长牛市时踏空。

**多因子（Multi-Factor）** 的思想是：把多个有效因子**合成**为一个综合得分，选"各方面都不错"的股票，从而分散单一因子的风险，让组合更稳健。

本策略用两个因子：**动量（越大越好）+ 市值（越小越好）**，采用最直观的**排序打分法**合成。

## 二、排序打分法（Rank Sum）原理

这是最简单、最鲁棒的因子合成方法，**不依赖因子原始数值的量纲**：

1. 对每个因子，把所有股票按因子值**排名**（第1名最优）；
2. 把各因子的**名次相加**，得到综合分；
3. 综合分越小（名次越靠前）越好。

| 股票 | 动量排名 | 市值排名 | 综合分 |
|------|---------|---------|--------|
| A    | 3       | 5       | 8  |
| B    | 10      | 2       | 12 |
| C    | 1       | 9       | 10 |

上表中 A 综合分最低（8），最优先入选。

**为什么用排名而不是原始值？** 因为动量的量纲是"百分比"、市值是"亿元"，直接相加毫无意义；而排名是无量纲的 1~N 整数，天然可比，且能自动抵抗极端值（再大的离群值也只是排第1）。

## 三、算法结构

```
每月第1个交易日 → rebalance
  ├─ 股票池：全市场 + 过滤 ST/退市/停牌/次新/涨跌停
  ├─ 因子1 市值：query(valuation.market_cap) → set_index('code')
  ├─ 因子2 动量：attribute_history 算 60 日涨幅
  ├─ 对齐：取两因子都有效的股票交集 codes
  ├─ 排名：动量降序 rank + 市值升序 rank
  ├─ 合成：total_rank = mom_rank + mkt_rank
  ├─ 取 total_rank 最小的 30 只
  └─ 换仓等权
```

## 四、函数详解

### 4.0 `df.set_index('code')` —— 必须记住的关键一步

本策略用 `get_fundamentals` 查市值，返回的 DataFrame 索引是 0,1,2... 数字序号，**不是股票代码**。必须显式 `set_index('code')`，否则后续 `mkt_df.index.intersection(mom.index)` 和 `mkt_df.loc[codes, ...]` 都会因索引不对齐而出错（详见策略3的 3.3 节）。

```python
mkt_df = get_fundamentals(q, date=context.current_dt.date())
mkt_df = mkt_df.set_index('code')     # 【关键】之后 index 才是股票代码
```

### 4.1 `Series.rank(ascending=...)` —— 排名

把一组数值转换成"名次"，返回新的 Series：

```python
s = pd.Series([10, 50, 30, 50])
s.rank(ascending=True)    # [1.0, 3.5, 2.0, 3.5]  升序，越小名次越前
s.rank(ascending=False)   # [4.0, 1.5, 3.0, 1.5]  降序，越大名次越前
```

- `ascending=True`：数值最小的排第1名（适合"越小越好"的因子，如市值、PE）；
- `ascending=False`：数值最大的排第1名（适合"越大越好"的因子，如动量、ROE）。

注意并列值会取**平均名次**（上面两个 50 都排 3.5），这是默认的 `method='average'` 行为。

### 4.2 因子方向要一致

这是最容易犯的错：**所有因子排名后必须"第1名都代表好"**。

```python
mom_rank = mom[codes].rank(ascending=False)   # 涨幅大→第1名（好）
mkt_rank = mkt_df.loc[codes, 'market_cap'].rank(ascending=True)  # 市值小→第1名（好）
```

两个 rank 的方向相反，但含义统一为"第1名=最好"，相加才有意义。

### 4.3 数据对齐：`intersection`

不同因子的股票覆盖范围不同（有的缺动量数据、有的缺市值数据），必须取**交集**，否则会出现 NaN 导致排名错误：

```python
codes = mkt_df.index.intersection(mom.index)
```

- `mkt_df.index` 是 Index 对象，`.intersection(other)` 返回两者共同元素的 Index；
- 之后用 `mom[codes]`、`mkt_df.loc[codes, 'market_cap']` 按同一顺序取值，保证一一对应。

### 4.4 综合排序

```python
total_rank = mom_rank + mkt_rank
target = total_rank.sort_values().index[:g.stock_num].tolist()
```

`sort_values()` 默认升序，综合分最小的排最前，取前 30 只的**索引（即股票代码）**。

## 五、回测说明

**回测参数（建议）：** 区间 2016-01-01 ～ 2026-01-01，初始资金 100 万，月度调仓，基准沪深300。

**关注指标：** 年化收益、最大回撤、夏普；与策略2（纯动量）、策略4（纯市值）对比，观察**双因子是否降低了回撤/波动**（这是多因子的核心价值，而非单纯追求最高收益）。

**如实说明：** 需在聚宽平台运行获取真实数据。风险提示：
- 排序打分法**等权**对待两个因子，隐含假设"两因子同样重要"，实际不一定成立（见策略9用 IC 定权重）；
- 两个因子都依赖的"小盘+动量"组合在 A 股历史上虽强，但**风格切换时回撤同样剧烈**。

## 六、改进方向

1. 因子数量从 2 个扩展到 4~5 个（见策略7）；
2. 用**因子标准化（z-score）** 替代排名，保留更多信息（见策略7）；
3. 给不同因子设置**权重**（如动量 0.6、市值 0.4），而非简单相加（见策略9）。
