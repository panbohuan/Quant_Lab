# 策略 10：机器学习选股（随机森林 Random Forest）

> 策略类型：机器学习选股（监督学习） ｜ 难度：★★★★★ ｜ 前置知识：策略7/9、机器学习基础概念

## 一、核心思路：把选股变成"预测问题"

前面的策略都是"**人脑定规则**"——人先想好因子、方向、权重。机器学习则是"**让模型从数据里自动学规律**"：

1. 把每只股票在某时点的特征（因子）记作样本 X；
2. 把该股票未来一段时间的涨跌记作标签 y；
3. 用**历史数据**训练一个分类器，让模型学会"什么样的特征组合容易涨"；
4. 对**当期**股票做预测，买入上涨概率最高的 K 只。

本策略选用**随机森林（Random Forest）**——一种经典、稳健、几乎不需要调参的集成学习算法，非常适合作为入门 ML 选股模型。

## 二、随机森林是什么（一句话理解）

随机森林 = 用多棵"决策树"投票。

- **决策树**：根据特征一步步做"if-else"判断（如"mom_20 > 5% 且 vol_20 < 2%" → 买），单棵树容易过拟合；
- **随机森林**：随机抽样训练多棵互不相同的树，最后**多数投票**，大幅降低过拟合、提升泛化能力。

优点：能捕捉特征间的非线性关系、对异常值不敏感、不需要特征标准化。缺点：可解释性弱于线性模型。

## 三、特征与标签（特征工程）

### 3.1 特征（Features）—— 模型的输入

本策略用 7 个**纯量价特征**（都由收盘价计算，无需基本面数据、无需对齐财报）：

| 特征 | 含义 |
|------|------|
| `mom_5/10/20/60` | 5/10/20/60 日动量（多周期趋势） |
| `vol_20` | 20 日收益率标准差（波动率，衡量风险） |
| `ma_bias` | 收盘价相对 20 日均线的偏离度（超买超卖） |

> 扩展：可加入 PE、ROE 等基本面特征（用 `get_fundamentals` 查询），或换手率、量比等，特征是 ML 模型的"原材料"，越有信息量越好。

### 3.2 标签（Label）—— 模型要预测的目标

```python
fwd_ret = close.iloc[i + horizon] / close.iloc[i] - 1   # 未来 horizon 日收益
label = (fwd_ret > 0).astype(int)                        # 涨=1，跌=0（二分类）
```

把"预测收益"简化为"预测涨跌"的分类问题，比回归更稳定、更易学。

## 四、防止"未来函数"（ML 选股最容易犯的致命错误）

**未来函数** = 用"未来才知道的信息"做决策，导致回测虚高。ML 选股必须严格保证：

```
训练样本在时点 i：
  特征 ← 只用 close.iloc[:i+1]（截至 i 的数据）
  标签 ← close.iloc[i+horizon]（i 之后的未来收益）
```

- 只要 `i + horizon` 仍早于"当前回测日期"，标签就是"已经发生的历史"，模型在**当前时点训练时完全可以知道**——这不违规；
- 但若把"当期特征"和"当期未来收益"配对训练，就违规了。

本策略通过 `range(feature_days, n - horizon, step)` 遍历历史时点，天然规避了未来函数。**请务必理解并复刻这一结构。**

## 五、算法结构

```
每隔 hold_days 个交易日 → check_and_trade → train_and_trade
  ├─ 股票池：沪深300 + 过滤 ST/退市/停牌/次新/涨跌停
  ├─ 拉取近 2 年收盘价矩阵 close
  ├─ 遍历历史时点 i（每 step 天采样）：
  │     特征 = compute_features(close[:i+1])
  │     标签 = (close[i+horizon]/close[i] - 1 > 0)
  ├─ 拼成训练集 X, y（dropna）
  ├─ 训练 RandomForestClassifier
  ├─ 当期特征 → predict_proba → 上涨概率
  ├─ 按概率取前 20 只
  └─ 换仓
```

## 六、函数详解

### 6.1 `RandomForestClassifier`

```python
from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100, max_depth=5, random_state=42)
model.fit(X, y)                                   # 训练
proba = model.predict_proba(cur)[:, 1]            # 预测：返回[跌概率, 涨概率]，取涨概率
```

- `n_estimators`：树的数量（越多越稳但越慢），100 是常用值；
- `max_depth`：树的最大深度，限制过拟合，5~10 常用；
- `random_state`：固定随机种子，保证结果可复现；
- `predict_proba` 返回每类概率，`[:, 1]` 取"上涨"这一类的概率。

### 6.2 `get_trade_days(start, end)` —— 交易日列表

```python
days = get_trade_days('2025-01-01', '2025-01-31')  # 返回该区间所有交易日（date 列表）
```

本策略用它统计"距上次调仓过了几个交易日"，实现"每隔 hold_days 个交易日重训一次"（比 `run_monthly` 更灵活，可设为任意天数）。

### 6.3 数据清洗

```python
X = pd.concat(X_list).replace([np.inf, -np.inf], np.nan).dropna()
```

特征里可能因停牌、次新股产生 NaN/inf（如除以 0），必须先 `dropna` 否则 sklearn 会报错。

### 6.4 最小样本保护

```python
if len(X) < 200:
    return
```

样本太少时模型训练无意义，直接跳过（保持原持仓），避免在数据不足时乱买。

## 七、回测说明

**回测参数（建议）：** 区间 2016-01-01 ～ 2026-01-01，初始资金 100 万，约每 20 交易日调仓，基准沪深300。

**关注指标：** 年化收益、最大回撤、夏普，以及**换手率**（ML 模型换手可能较高）。

**如实说明：** 需在聚宽平台运行获取真实数据（本策略计算量大，回测较慢，属正常）。风险提示：
- **过拟合**是 ML 最大风险：特征少、样本少、调参多都会让回测好看但实盘失效，务必用样本外验证；
- 随机森林的"概率"不是真实概率，仅用于相对排序；
- 分类标签"涨跌"丢失了涨跌幅信息，进阶可改回归或排序学习（Learning to Rank）。

## 八、改进方向

1. **换更强模型**：梯度提升树 GBDT / XGBoost / LightGBM（`from sklearn.ensemble import GradientBoostingClassifier` 或 lightgbm 库）；
2. **增加基本面特征**：PE、ROE、营收增速等（`get_fundamentals` 查询后并入特征）；
3. **滚动重训 + 样本外验证**：用时间序列交叉验证（而非随机切分）评估模型，避免高估；
4. **加正则与特征选择**：特征重要性排序（`model.feature_importances_`），剔除无效特征。
