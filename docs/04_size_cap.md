# 策略 4：单因子小市值选股（Size / 市值因子）

> 策略类型：单因子选股（基本面·规模） ｜ 难度：★★☆☆☆ ｜ 前置知识：策略3（query/get_fundamentals）

## 一、核心思路：小市值效应（Size Effect）

**市值（Market Cap）** 是上市公司规模的度量：

$$\text{总市值} = \text{股价} \times \text{总股本}$$

**小市值效应**：长期来看，**小市值股票的平均收益率显著高于大市值股票**。这是全球最经典的市场异象之一（Banz, 1981 首次在美股发现；在 A 股该效应尤其显著，历史上"炒小炒新"盛行）。

**为什么小市值能跑赢？（常见解释）**
1. **风险补偿**：小公司经营不确定性更高、信息不透明、流动性差，投资者要求更高的风险溢价；
2. **成长空间**：小公司基数低，成长弹性更大；
3. **被关注度低**：分析师覆盖少，定价效率低，更容易被低估；
4. **A 股特殊制度**：壳资源价值、并购重组预期等历史因素放大了小市值溢价。

> ⚠️ 风险提示：小市值策略在 A 股 2017 年、2021 年之后曾遭遇剧烈回撤（"大小盘切换"、注册制下壳价值消退、退市常态化）。它是**高收益高波动**的典型因子，需谨慎。

## 二、算法结构

与策略3完全相同，仅把因子从 `pe_ratio` 换成 `market_cap`，排序方向保持"升序"（市值越小越靠前）：

```
每月第1个交易日 → rebalance
  ├─ 股票池：全市场
  ├─ 过滤 ST / 停牌
  ├─ 查询 valuation.market_cap（总市值）
  ├─ 清洗 dropna + >0
  ├─ 按市值升序取前 30 只
  └─ 换仓等权
```

## 三、函数详解

### 3.1 总市值 vs 流通市值

```python
valuation.market_cap              # 总市值 = 股价 × 总股本
valuation.circulating_market_cap  # 流通市值 = 股价 × 流通股本
```

- **总市值**反映公司整体规模；
- **流通市值**只计算可自由交易的股份，与真实可交易性更贴近。

A 股存在大量限售股，因此**流通市值**往往比总市值更能反映一只股票真实的"交易规模"。实操中两者都常用，可自行切换 `g.cap_field` 对比。

### 3.2 `get_all_securities(types, date)` —— 获取全市场标的

返回指定类型的所有证券信息（DataFrame，索引是代码）：

```python
all_stocks = get_all_securities(['stock'], date=context.current_dt.date())
pool = all_stocks.index.tolist()    # 所有A股代码列表
```

- `types`：`'stock'`（股票）、`'index'`（指数）、`'etf'`、`'futures'`（期货）等，可传列表；
- `date`：取该日期存在的证券（自动剔除当时还没上市/已退市的股票）。

**为什么小市值策略要全市场选股？** 小市值股票通常不在沪深300等大盘指数成分里，若用沪深300做股票池就选不到真正的小盘股了，所以必须用全市场。

### 3.3 市值字段的单位

聚宽 `valuation.market_cap` 的单位是**亿元**。在排序时单位不影响结果（只是统一放大/缩小），但如果你要设定"市值阈值"（如剔除 20 亿以下的微盘股），需要注意单位换算。

## 四、回测说明

**回测参数（建议）：** 区间 2016-01-01 ～ 2026-01-01，初始资金 100 万，月度调仓，基准沪深300。

**关注指标：** 年化收益、最大回撤、夏普，尤其关注**最大回撤和风格切换风险**。

**如实说明：** 需在聚宽平台运行获取真实数据。风险提示（重要）：
- 小市值因子**回撤巨大且集中在特定时期**（如 2017 年白马行情、2024 年初微盘股流动性危机）；
- **流动性风险**：微盘股成交清淡，真实交易中的冲击成本远高于回测设定的滑点；
- **幸存者偏差**：历史回测若只含"现在还活着"的股票，会高估小市值收益（退市股被遗漏）。聚宽 `get_all_securities(date=...)` 已尽量规避此问题，但仍需警惕。

## 五、改进方向

1. 剔除**次新股**（上市不满 N 天），次新股波动大、壳预期强，会干扰因子纯度；
2. 设定**市值下限**，过滤流动性极差的微盘股；
3. 市值因子与动量/价值因子结合（见策略6、7），降低单一风格风险。
