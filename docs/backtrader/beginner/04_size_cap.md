## 一、这一篇你将学到什么

- **规模因子（Size）**：A 股最著名的异象之一；
- `total_mv`（总市值）与 `circ_mv`（流通市值）的差别，以及为什么"用哪个"会改变结果；
- 与策略 3 完全相同的那套骨架（`value_panel` + `asof` + 排序 + `equal_weight_order`）——**换一个字段就是一个新因子**；
- 一个必须警惕的陷阱：**小市值策略的收益有很大一部分来自"幸存者偏差 + 流动性幻觉"**。

**读完你应该能回答**：为什么小市值策略在这份回测里赚了 689%，却有人说"它不能实盘"？

## 二、心智模型：这个策略在时间轴上长什么样

```
每月第一个交易日（收盘后）
   │
   ├─ 1. asof(panel, cur)：取截至今天已公布的最新一期总市值
   ├─ 2. 剔除 ≤ 0（异常值）
   ├─ 3. 按市值从小到大排序（升序 = 最小）
   ├─ 4. 取最小的 10 只，等权买入（每只 ≈ 9.8% 仓位）
   └─ 5. 次日开盘成交
```

**和策略 3 的唯一区别**：那篇按 PB **升序**（越小越便宜），这篇按 total_mv **升序**（越小越好）——**代码几乎一样，只是"因子"换了**。

---

## 三、核心思路

**小市值效应（Small Cap Premium）**：长期看，**市值小的股票平均收益高于市值大的股票**，A 股尤其明显。

**为什么？** 三种常见解释：

| 解释 | 说明 |
|---|---|
| **风险补偿** | 小公司经营不确定性大、流动性差，投资者要求更高回报 |
| **壳价值**（A 股特有） | 过去 IPO 审批制下，小市值公司有"借壳"预期，享受额外估值 |
| **关注度低** | 机构覆盖少、定价不充分，容易出现错误定价 |

**两种市值口径**：

| 字段 | 含义 | 什么时候用 |
|---|---|---|
| `total_mv` | 总市值 = 股价 × **总股本**（含限售股） | 衡量公司规模 |
| `circ_mv` | 流通市值 = 股价 × **可流通股本** | 衡量"能买多少"（流动性） |

本策略默认用 `total_mv`。改成 `circ_mv` 会**更贴近"实际可交易的盘子"**，结果通常不同。

> **必须知道的背景（否则会误读回测）**：
> 1. **幸存者偏差最严重的一篇**：股票池是"当前沪深300成分股"——而小市值公司能一路活到今天并进入沪深300，本身就是极端的幸存者。真实历史上，小市值股票**退市、被借壳、长期停牌**的比例很高。
> 2. **2017 年后小市值效应明显减弱**：注册制、退市新规、机构化，壳价值缩水。
> 3. **流动性幻觉**：小市值股票成交额小，回测里"10% 仓位"能轻松买进去，实盘可能要买好几天（冲击成本）。

## 四、算法结构

```
main() → load_index_members → load_universe → __CAL__ → run_strategy
   │
   └─ SmallCap.__init__()
         └─ self.panel = value_panel(codes, 'total_mv')
   │
   └─ 每月 on_rebalance(cur)
         ├─ row = asof(self.panel, cur)      ← 只取 ≤ cur
         ├─ row = row[row > 0]               ← 剔除异常
         ├─ 样本 < 10 → 不调仓
         ├─ row.sort_values()                ← 升序 = 市值最小
         ├─ 取前 10 → equal_weight_order()
         └─ 次日开盘成交
```

## 五、代码逐段详解

### 5.1 参数

```python
START = '2018-01-01'        # 市值数据（东财）约 2018 年起
UNIVERSE_SIZE = 40
TOPN = 10
FACTOR = 'total_mv'         # 'total_mv' 总市值 / 'circ_mv' 流通市值
```

### 5.2 与策略 3 完全同构的两个方法

```python
class SmallCap(PanelStrategy):
    params = (('topn', TOPN), ('rebalance', 'monthly'),)

    def __init__(self):
        super().__init__()
        codes = [d._name for d in self.tradables]
        self.panel = value_panel(codes, FACTOR)      # ← 只换了字段名

    def on_rebalance(self, cur):
        row = asof(self.panel, cur)                  # 防未来函数
        if row is None or len(row) < self.p.topn:
            return
        row = row[row > 0]                           # 市值必须为正
        names = [c for c in row.sort_values().index[:self.p.topn]   # 升序=最小
                 if c in self.getdatanames()]
        self.equal_weight_order(names, cur)
```

**请对照策略 3 一起看**：

| | 策略 3（低估值） | 策略 4（小市值） |
|---|---|---|
| 字段 | `'pb'` | `'total_mv'` |
| 排序 | `sort_values()` 升序 | `sort_values()` 升序 |
| 金融含义 | PB 越小越**便宜** | 市值越小越**小盘** |
| 代码差异 | **只有字段名一个参数** | —— |

> **这就是"因子 = 一个可排序的横截面数值"这个抽象的价值**：换因子不用重写策略骨架。
> **但也要小心**：代码同构 ≠ 逻辑同构。"便宜"和"小"是两种完全不同的风险暴露。

### 5.3 单位提醒

`total_mv` 的单位是**元**（东财口径）。所以"市值最小的 10 只"通常是几十亿到几百亿的公司，而不是几千万——如果你想看具体数值，可以打印：

```python
print(f'  [{cur}] 入选市值（亿元）：{[round(row[c] / 1e8, 1) for c in names]}')
```

## 八、回测结果怎么读

| 指标 | 数值 | 怎么理解 |
|---|---|---|
| 累计收益率 | **+689.93%** | 全场最高之一 |
| 年化收益率 | **+27.80%** | 非常亮眼 |
| 最大回撤 | **−29.58%** | 相对收益来说不算大 |
| 夏普比率 | **1.19** | 全场最高之一 |
| 成交笔数 | 1058 | 月频调仓 |

**必须冷静地读这张表：**

1. 数字确实漂亮，但**它是本仓库里"最不可信"的一篇**——原因见第三节的三条背景；
2. 具体来说：**当前成分股 + 沪深300（大盘股指数）里挑最小** = 你挑的其实是"大公司里的小公司"，它们退市概率低、流动性好，天然比真正的小盘股安全得多；
3. 如果换成**中证1000/中证2000 + 历史成分股**，收益会大幅下降、回撤会大幅上升。

> **教学价值**：这一篇的意义不是"发现了一个赚钱策略"，而是让你亲眼看到 —— **同一个因子，样本口径一变，结论可以差好几倍**。这也是为什么严谨的研究都要做"样本外 + 去幸存者"检验。

## 九、易混点与常见错误

| 症状 | 原因 | 正确做法 |
|---|---|---|
| 排序反了，买成最大市值 | 忘记这是"升序=最小" | 明确写下"升序 = 市值最小"的注释 |
| 以为 total_mv 和 circ_mv 一样 | 一个有总股本、一个只有流通股本 | 明确口径；流动性敏感的策略用 `circ_mv` |
| 直接拿这个收益当预期 | 幸存者偏差 + 流动性幻觉 | 只看"因子方向"，不看绝对收益 |
| 调仓时买不进 | 小市值流动性差 | 加成交额过滤；或限制单只仓位 |

## 十一、改进方向（思考题）

1. **换口径**：把 `FACTOR` 改成 `'circ_mv'` 再跑，看差异。
2. **加流动性过滤**：剔除日均成交额低于某阈值的股票，模拟真实的冲击成本。
3. **行业中性化**：小市值里银行/地产占比高，做行业中性化（策略 8）能看出"纯规模"的效果。
4. **换股票池**：改成中证1000 成分股，观察"更小盘"的收益与风险如何变化（本仓库的 `load_index_members` 支持传入指数代码）。
