## 一、这一篇你将学到什么

策略 7 给四个因子**固定权重**（1:1:1:1）。这一篇要问：**因子是不是也该看"什么时候用"？**

| 你会搞懂 | 一句话 |
|---|---|
| **因子也具有周期性** | 没有永远有效的因子，只有适合当下环境的因子 |
| **市场温度** | 用沪深300 PE 的历史分位数衡量"贵不贵" |
| **Regime 切换** | 高估 → 防守（质量+估值）；低估 → 进攻（动量） |
| 分位数比绝对值稳健 | 估值中枢会随时代漂移，分位不会 |

**读完你应该能回答**：为什么"高估时超配质量和低估值、低估时超配动量"？

## 二、心智模型：先看"贵不贵"，再决定用哪套因子

```
每月调仓（收盘后）
   │
   ├─ 1. 算"市场温度"：
   │       取沪深300 的历史 PE（月度，2005 年起）
   │       温度 = 当前 PE 在历史 PE 中的分位（0~1）
   │       （历史不足 36 个月 → 无法判断，用均衡权重）
   │
   ├─ 2. 按温度切换因子权重：
   │       温度 > 70%（贵、拥挤） → 防守：ROE×1.5、PB×1.5、动量×0.3、市值×0.5
   │       温度 < 30%（便宜）     → 进攻：ROE×0.7、PB×0.7、动量×2.0、市值×1.0
   │       其余                  → 均衡：全部 ×1.0
   │
   ├─ 3. 用这组权重合成四因子得分
   └─ 4. 取前 10 → 等权买入 → 次日开盘成交
```

**一张表看懂三种状态**：

| 温度 | 市场状态 | 该买什么 | 直觉 |
|---|---|---|---|
| > 70% | 高估、拥挤 | 质量（ROE）+ 低估值 | "贵的时候买便宜的好公司" |
| < 30% | 低估 | 动量 | "便宜的时候买正在转强的" |
| 30%~70% | 中间 | 均衡 | 不动 |

## 三、核心思路

**因子择时（Factor Timing）** 的前提是：**因子的有效性会随市场环境变化。**

- 牛市/情绪高涨期：**动量**往往有效（追涨）；
- 熊市/恐慌期：**质量**和**低估值**更抗跌（防守）；
- 所以"用哪个因子"应该取决于**当前的市场状态**。

**市场状态怎么量化？—— 用估值的分位数当"温度计"：**

$$\text{温度}_t = P(PE_{history} < PE_t)$$

即"当前 PE 在历史上处于什么位置"：

| 温度 | 含义 |
|---|---|
| 0.9（90 分位） | 比历史上 90% 的时间都贵 |
| 0.3 | 比历史上 70% 的时间便宜 |

**为什么用分位数而不是 PE 的绝对值？** 因为估值中枢会随时代漂移（2005 年 A 股整体 40 倍 PE，现在 12 倍很常见）。**分位数是相对的，自动适应时代。**

> **常见误解**：因子择时听起来很美，但它是**双重预测**——你既要预测"市场会怎么走"，又要预测"哪个因子会有效"。**预测错一次，两头挨打**（比如你判断"高估 → 转防守"，结果市场继续涨，动量因子继续赢）。
>
> 所以本策略的权重变化**刻意不极端**（最大 2.0 倍，最小 0.3 倍），而不是"全押一个因子"。

## 四、算法结构

```
main() → load_index_members → load_universe → __CAL__ → run_strategy
   │
   └─ FactorTiming.__init__()
         ├─ self.pb  = value_panel(codes, 'pb')
         ├─ self.mv  = value_panel(codes, 'total_mv')
         ├─ self.roe = roe_panel(codes, lag_days=45)
         └─ self.pe  = load_index_pe('沪深300')          ← 月度 PE
   │
   └─ 每月 on_rebalance(cur)
         ├─ asof 取 pb/mv/roe；hist_close 算动量
         ├─ 四者取交集、过滤 pb>0 / mv>0
         ├─ pct = self._temperature(cur)                 ← 市场温度
         ├─ w, regime = self._weights(pct)               ← 权重切换
         ├─ score = w组合四个 z-score
         └─ 取前 10 → equal_weight_order()
```

## 五、代码逐段详解

### 5.1 参数与阈值

```python
HIGH_PCT = 0.70             # 估值分位高于此 → risk-off
LOW_PCT = 0.30              # 估值分位低于此 → risk-on
ROE_LAG = 45
```

### 5.2 市场温度：分位数怎么算

```python
def _temperature(self, cur):
    s = self.pe.loc[:pd.Timestamp(cur)].dropna()   # ① 只取 ≤ cur 的历史 PE
    if len(s) < 36:                                # ② 历史不足 36 个月 → 不判断
        return None
    return float((s < s.iloc[-1]).mean())          # ③ 当前值在历史中的分位
```

| 步骤 | 作用 |
|---|---|
| `self.pe.loc[:cur]` | **切掉未来**：只用截至今天的 PE 序列（防未来函数） |
| `len(s) < 36` | 历史太短时"分位数"没有意义 |
| `(s < s.iloc[-1]).mean()` | 历史上有多少比例的月份 PE 比现在低 = 当前分位 |

> **注意**：`self.pe` 是在 `__init__` 里一次性加载的**完整历史**（包含 2026 年的数据）。所以每一期都必须用 `.loc[:cur]` 切片——**这是本篇唯一但致命的风险点**。

### 5.3 按温度切换权重

```python
def _weights(self, pct):
    if pct is None:
        return {'roe': 1.0, 'pb': 1.0, 'mom': 1.0, 'mv': 1.0}, '均衡(历史不足)'
    if pct > HIGH_PCT:
        return {'roe': 1.5, 'pb': 1.5, 'mom': 0.3, 'mv': 0.5}, '高估 → 防守'
    if pct < LOW_PCT:
        return {'roe': 0.7, 'pb': 0.7, 'mom': 2.0, 'mv': 1.0}, '低估 → 进攻'
    return {'roe': 1.0, 'pb': 1.0, 'mom': 1.0, 'mv': 1.0}, '均衡'
```

**读这张权重表**（注意方向：pb 和 mv 在 score 里是**减号**）：

| 状态 | ROE | PB | 动量 | 市值 |
|---|---|---|---|---|
| 高估 → 防守 | **1.5**（更看重质量） | **1.5**（更看重便宜） | **0.3**（压低追涨） | 0.5 |
| 低估 → 进攻 | 0.7 | 0.7 | **2.0**（重点追涨） | 1.0 |

### 5.4 合成与打印

```python
score = (w['roe'] * zscore(roe) - w['pb'] * zscore(pb)
         + w['mom'] * zscore(mom) - w['mv'] * zscore(mv))
names = score.sort_values(ascending=False).index[:self.p.topn].tolist()
self.equal_weight_order(names, cur)
print(f'  [{cur}] 估值分位 {"N/A" if pct is None else f"{pct:.0%}"} → {regime}')
```

打印出来的日志，就是这一篇最直观的"教学材料"（见下一节）。

## 六、一次真实运行的轨迹

```
  [2018-01-02] 估值分位 62% → 均衡
  [2018-06-01] 估值分位 48% → 均衡
  [2018-12-03] 估值分位 21% → 低估 → 进攻
  [2019-04-01] 估值分位 55% → 均衡
  [2021-02-01] 估值分位 88% → 高估 → 防守
  [2024-09-02] 估值分位 12% → 低估 → 进攻
```

**怎么读这串日志**：

- **2018 年底分位 21%**：市场极度悲观 → 策略切换到"进攻"（加码动量）；
- **2021 年初分位 88%**：核心资产泡沫顶点 → 策略切换到"防守"（加码质量+估值）；
- 这两个切换**恰好对应了行情的转折**——但请记住：**这是事后来看**，策略在当期并不知道。

## 八、回测结果怎么读

| 指标 | 数值 | 怎么理解 |
|---|---|---|
| 累计收益率 | **+208.81%** | 优于静态多因子（+295.75%）？不，是**低于** |
| 年化收益率 | **+14.32%** | —— |
| 最大回撤 | **−32.64%** | 与静态多因子（−32.38%）几乎一样 |
| 夏普比率 | **0.69** | 低于静态多因子（0.82） |
| 成交笔数 | 1318 | 月频 |

**"择时反而跑输不择时"——这个结果值得好好想：**

1. **因子择时是"双重预测"**：先预测市场状态、再预测哪类因子有效，两次都可能错；
2. **分位数是个慢信号**：PE 分位从 88% 回到 50% 可能要一年，切换太慢；
3. **权重变化带来额外换手**（1318 笔），成本上升；
4. 结论：**在本回测里，"老老实实等权"（策略 7）比"聪明地择时"更好**。

> **教学价值**：这一篇的价值不在收益，而在于让你理解 **"因子也有周期"** 这个视角，以及"**增加复杂度不一定提升表现**"这条经验。

## 九、易混点与常见错误

| 症状 | 原因 | 正确做法 |
|---|---|---|
| 回测收益虚高 | `self.pe` 没做 `.loc[:cur]` 切片 | 每期必须切片（防未来函数） |
| 早期分位乱跳 | 历史不足 36 个月 | 代码里已返回 None → 用均衡权重 |
| 权重方向搞反 | pb/mv 在 score 里是减号 | 权重是"重视程度"，不是"方向" |
| 以为这是"择时买卖" | 它只改因子权重 | 始终满仓（通过 equal_weight_order 的 0.98） |
| 换手变高 | 权重变化导致排序变化 | 可以加"权重平滑" |

## 十一、改进方向（思考题）

1. **换温度计**：用"股债利差"（沪深300 股息率 − 十年国债收益率）代替 PE 分位。
2. **平滑切换**：不要一步从 2.0 跳到 0.3，改成每月最多变 0.3。
3. **加波动率 regime**：不只看估值高低，还看市场波动率高低。
4. **回测更长区间**：本策略 START=2018（估值数据限制），可以换成只有 PE 的更长区间做因子侧检验。
