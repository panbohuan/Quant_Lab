## 二、心智模型：谁跌得最狠就买谁

```
每周第一个交易日（收盘后）
   │
   ├─ 1. 算每只票"过去 5 个交易日"的累计涨跌幅
   │
   ├─ 2. 只留下跌幅 ≤ −8% 的（真超跌）
   │       一个都没有 → 清仓（空仓等待）
   │
   ├─ 3. 跌得最狠的排前面，取前 10 只
   │
   └─ 4. 等权买入 → 次日开盘成交 → 下周一再评估
```

**和动量策略正好相反**：

| | 动量（策略 2） | 本篇（均值回归） |
|---|---|---|
| 买什么 | 前期**涨得最多**的 | 前期**跌得最狠**的 |
| 时间尺度 | 60 日（中期） | 5 日（短期） |
| 逻辑 | 强者恒强 | 过度反应后的修复 |

**为什么两者能同时成立？** 因为时间尺度不同：**短期容易反转（跌多了反弹），中期容易延续（趋势）。** 这是 A 股的常见现象组合。

## 三、核心思路

**均值回归（Mean Reversion）**：价格短期偏离太多后，会**向均值回归**。

**行为金融解释**：

1. **过度反应**：坏消息出来时，投资者恐慌抛售，价格跌过头；
2. **流动性冲击**：大额卖出把价格打下去，卖压结束后价格修复；
3. **短期资金博弈**：超跌股吸引抄底资金。

**本策略的规则**：

$$score = \frac{P_t}{P_{t-5}} - 1 \le -8\%$$

**跌超过 8% 才算"超跌"**，然后买跌得最狠的 10 只。

> **⚠️ 本篇的降级说明（一定要读）**
>
> **聚宽原版是"日内"策略**：用分钟级数据，捕捉"开盘 30 分钟跌超 2% → 反弹"这种机会。
> **本地免费源拿不到稳定的分钟级历史数据**（东财分钟接口经常限流/不可达），所以本地版**降级为日线**：
> - 观测窗口从"30 分钟"放大到"5 个交易日"；
> - 调仓频率从"日内多次"改成"每周一次"。
>
> 原理一致（都是"过度反应后的修复"），但**时间尺度变了，结论不能互相套用**。想真做日内，需要 tushare / 米筐等付费数据源。

> **⚠️ 成本是这类策略的命门**
> 短周期策略的换手极高。本策略 **累计换手率 2 万%+**，意味着：
> - 每一次调仓都要付佣金（双向 0.03%）+ 印花税（卖 0.05%）+ 滑点（单边 0.02%）；
> - **一年下来光摩擦成本就是十几个百分点**——这也是为什么"看起来很赚"的短周期策略实盘常常亏钱。

## 四、算法结构

```
main() → load_index_members → load_universe → __CAL__ → run_strategy
   │
   └─ ShortTermReversal.on_rebalance(cur)（每周）
         ├─ 算每只票过去 5 个交易日的涨跌幅
         ├─ oversold = {跌 ≤ −8% 的}
         ├─ 若 oversold 为空 → close_all()（空仓）
         ├─ 否则：按涨幅**升序**（跌得最狠的在最前）取前 10
         └─ equal_weight_order(names, cur)
```

## 五、代码逐段详解

### 5.1 参数

```python
TOPN = 10
WINDOW = 5                  # 回看 5 个交易日
THRESHOLD = -0.08           # 累计跌幅超过 8% 才算"超跌"
REBALANCE = 'weekly'        # 每周调仓（约持有 5 个交易日）
```

| 参数 | 改了会怎样 |
|---|---|
| `WINDOW` | 5 → 10：窗口更长、信号更少但更"深跌" |
| `THRESHOLD` | −0.08 → −0.05：信号更多、换手更高；→ −0.15：信号很少 |
| `REBALANCE` | 改成 `'daily'` 换手会爆炸（成本吃掉一切） |

### 5.2 选股 + 空仓纪律

```python
def on_rebalance(self, cur):
    scores = {}
    for d in self.tradables:
        if not self.live(d, cur):
            continue
        closes = self.hist_close(d, self.p.window + 1)
        if closes is None or closes[0] <= 0:
            continue
        scores[d._name] = closes[-1] / closes[0] - 1.0

    oversold = {k: v for k, v in scores.items() if v <= self.p.threshold}
    if not oversold:
        self.close_all(cur)                    # ← 没有超跌股就空仓
        return
    names = sorted(oversold, key=oversold.get)[:self.p.topn]   # 升序 = 跌得最狠
    self.equal_weight_order(names, cur)
```

| 代码 | 作用 |
|---|---|
| `closes[-1] / closes[0] - 1` | 5 日累计涨跌幅（`get()` 返回 array：`[0]` 最旧、`[-1]` 最新） |
| `v <= THRESHOLD` | 只要"跌够多"的，涨的、横盘的都不要 |
| `if not oversold: close_all()` | **空仓纪律**：没有信号就不硬凑 |
| `sorted(..., key=oversold.get)` | 默认**升序** → −20% 排在 −9% 前面 → 跌得最狠优先 |

> **一个容易被忽略的点**：这里**没有"止损"**。买进去之后如果继续跌，要等到下一周重新评估才可能被卖出。这是"逆势买入"的固有风险——**你买的正是正在下跌的股票**。

## 八、回测结果怎么读

| 指标 | 数值 | 怎么理解 |
|---|---|---|
| 累计收益率 | **+222.89%** | 不错 |
| 年化收益率 | **+10.90%** | —— |
| 最大回撤 | **−66.75%** | ⚠️ **全场最大**（几乎腰斩再腰斩） |
| 夏普比率 | **0.50** | 一般 |
| 成交笔数 | 1809 | 周频，换手极高 |

**要点：**

1. **收益看起来不错，但 −66.75% 的回撤意味着**：如果你在最高点进场，资产一度只剩三分之一——**绝大多数人撑不到后面的反弹**；
2. **逆势买入的固有风险**：你买的是"正在跌的股票"，如果它是因为基本面恶化而跌（不是情绪），那它**不会回归**；
3. **成本极高**：1809 笔 + 周频换手，摩擦成本已经体现在收益率里；
4. **降级影响**：本地版是"5 日反转"，与聚宽原版的"日内反弹"不是一回事。

> **教学价值**：这一篇教会你两件事——① **均值回归策略的风险特征**（高换手、大回撤、依赖反弹）；② **数据可得性如何迫使策略降级**，以及"降级后名字还叫 intraday"时必须**明确标注差异**。

## 九、易混点与常见错误

| 症状 | 原因 | 正确做法 |
|---|---|---|
| 选出了涨的股票 | 忘记过滤 `v <= threshold` | 只买"跌够多"的 |
| 排序反了（买跌最少的） | 用了 `reverse=True` | 升序 → 跌得最狠的排最前 |
| 没有信号还满仓 | 忘了 `close_all()` | 无超跌股必须空仓 |
| 以为这是"日内策略" | 名字叫 intraday | 本地版已降级为日线周频 |
| 回撤巨大 | 逆势买入 + 无止损 | 认识其固有风险；可加止损或基本面过滤 |

## 十一、改进方向（思考题）

1. **加基本面过滤**：只买"财务正常、只是被错杀"的超跌股，避开"基本面恶化"的。
2. **加止损**：买入后跌 5% 立即止损，控制尾部风险。
3. **改成分钟级**：接入付费分钟数据，恢复原版的日内逻辑。
4. **组合动量 + 反转**：一半仓位做中期动量、一半做短期反转，降低整体波动。
