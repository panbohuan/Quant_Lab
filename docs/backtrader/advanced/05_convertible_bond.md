# 进阶策略 5：可转债双低策略（Convertible Bond）· backtrader 本地版

> 类型：跨品种 / 可转债 ｜ 难度：★★★★☆
> 前置知识：`listed_bonds` / `load_bond_daily` / `bond_symbol`、静态溢价率快照、`PanelStrategy`、MIN_COVERAGE 覆盖率
> **运行框架：backtrader（本地回测 + 免费数据）** ｜ 本策略的**聚宽云端版**见 [docs/joinquant/advanced/05_convertible_bond.md](../../joinquant/advanced/05_convertible_bond.md)

## 一、核心思路

这是从"股票"拓展到"可转债"的第一课。可转债 = 债券 + 看涨期权：

- **债性**：股价不涨，至少拿回本金 + 利息（下有保底）；
- **股性**：股价大涨，可转成股票跟着赚（上不封顶）。

「双低策略」挑"**价格低 + 转股溢价率低**"的品种：

- **价格低**：接近债底，下跌空间小（保底）；
- **转股溢价率低**：转债价与转股价值差距小，股性足（弹性好）。

经典双低公式：

```
双低值 = 转债价格 + 转股溢价率(%)
双低值越小越好 → 越"便宜"
```

给新手的直觉：买"价格接近债底（保底）+ 溢价率低（弹性好）"的转债，实现"跌有限、涨无限"的赔率优势。

本策略参数一览（文件顶部常量）：

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `START` / `END` | `2019-01-01` / `2025-06-30` | 固定区间（数据可靠性限制，见 3.4） |
| `CASH` | `1_000_000` | 初始资金 100 万 |
| `MAX_CANDIDATES` | `60` | 按发行规模取前 60 只作候选池 |
| `MIN_COVERAGE` | `0.50` | 数据覆盖度下限（区间交易日 × 50%） |
| `TOPN` | `5` | 持有双低值最小的 5 只 |

聚宽版是 `get_all_securities(types=['cb'])` 全市场 + 真实历史溢价率 + 持有 10 只；本地版因数据源限制改为"发行规模 Top60 + 静态溢价率快照 + 持有 5 只 + 固定 2019~2025 区间"。

## 二、算法结构（分步拆解）

```
main() → build_bond_universe()：listed_bonds 取前 N 大发行规模
   │
   ├─ 对每只：load_bond_daily，检查覆盖度 >= MIN_COVERAGE
   │      └─ 不足 → 剔除（防"数据断层"误判）
   │
   └─ run_strategy() 启动回测
         │
         └─ 每月 next()（PanelStrategy monthly）→ on_rebalance(cur)
               │
               ├─ 1. 遍历 premium 快照：code 在 datas 且 live(d,cur) 且 price>0
               ├─ 2. 双低值 = price + premium（premium 为 NaN → 0）
               ├─ 3. 候选不足 topn → 跳过
               ├─ 4. 按双低值升序取前 topn 只
               └─ 5. equal_weight_order(target, cur) 等权买入
```

## 三、代码逐段详解 + backtrader 语法解析（本篇重点：可转债数据）

### 3.0 数据源 API：`listed_bonds` / `load_bond_daily` / `bond_symbol`

| 函数 | 返回 | 说明 |
|------|------|------|
| `listed_bonds(before, top, min_size)` | `DataFrame([bond_code, bond_name, list_date, price, conv_price, premium, issue_size, rating])` | 在 `before` 前上市的可转债，按发行规模降序；`premium` 是**当前时点快照** |
| `load_bond_daily(code, start, end)` | `DataFrame[open,high,low,close,volume]` | 单只转债日线（新浪，上市日起） |
| `bond_symbol(code)` | `str` | 转债代码归一化：沪市 `11x/113/118` → `sh`，深市 `123/127/128` → `sz` |

`build_bond_universe` 就是：`listed_bonds(before=START, top=60)` 取候选 → 逐只 `load_bond_daily` 查覆盖度 → 通过 `MIN_COVERAGE` 的才进 `data`，同时把 `row['premium']` 收进 `premium` 字典（静态快照）。

### 3.1 可转债代码规范化 `bond_symbol`

```python
data[bond_symbol(code)] = df
premium[bond_symbol(code)] = row['premium']
```

`btlab.datasource.bond_symbol` 把 6 位代码归一化：沪市 `110/111/113/118xxx` → `sh`，深市 `123/127/128xxx` → `sz`。这是回测喂数据与策略取数"同名的保证"——`adddata(name=...)` 用归一化名，`getdatabyname` 才能对上。与股票 `normalize_code` 同理，但转债号段不同，需单独函数。

### 3.2 候选池与覆盖率门槛 `MIN_COVERAGE`

```python
table = listed_bonds(before=START, top=MAX_CANDIDATES)    # 上市早于 2019 的 Top60 发行规模
...
df = load_bond_daily(code, start=START, end=END)
if len(df) < total_days * MIN_COVERAGE:                   # 覆盖度 < 50% → 剔除
    continue
```

- `listed_bonds(before=START, top=60)` 取"2019 年前上市、发行规模最大"的 60 只候选（规模大 = 流动性好、不易退市）。
- `MIN_COVERAGE = 0.50`：转债在区间内的交易日数需 ≥ 总交易日 × 50%。中途强赎/到期退市的转债数据会断崖，`len(df)` 骤减，**覆盖率不足直接剔除**，避免"用残缺数据假装有持仓"。
- 结果：候选 60 → 数据可用仅 **11 只**（日志可见）。样本很小，结论要谨慎。

### 3.3 静态转股溢价率快照的局限性（最重要）

```python
scored[code] = price + prem          # prem 来自 listed_bonds 的 row['premium']
```

聚宽能查任意历史时点的真实转股溢价率；本地免费源（新浪/东财）只有**当前时点**的溢价率快照。因此：

- 本策略的"双低值"实际是 `现价 + 当前溢价率`，溢价率**不随时间变化**（整段回测用同一个静态值）。
- 这意味着策略**退化为"以低价为主、静态溢价率微调"**，与聚宽版"真实双低"（溢价率每日更新）行为不一致。
- 局限来源：可转债溢价率历史序列免费源缺失，`listed_bonds` 的 `premium` 字段明确标注是"当前时点快照"（见 datasource.py 注释）。

> 诚实结论：本地版"双低"只有一半是真的（低价是动态的，溢价率是静态的）。要还原真实双低，需接入能回放历史溢价率的付费/专业数据源。

一个"双低值"的计算例子（静态溢价率场景）：

```
某转债 现价 price   = 110 元
静态溢价率 premium   = 12.0 (%)      ← 整段回测用同一个值
双低值 = 110 + 12.0 = 122.0
```

另一只：`price=105, premium=20.0` → 双低值 `125.0`。则第一只（122.0）更小、更优先入选。注意：若用**真实历史溢价率**，第一只的溢价率可能早已变到 25%，双低值就变成 135，排名会反转——这正是静态快照导致"选股失真"的具体机制。

### 3.3.1 `MIN_COVERAGE` 过滤的具体效果

`total_days` 是区间 `2019-01-01 ~ 2025-06-30` 的交易日总数（约 1573）。某转债若只覆盖到 700 个交易日：`700 / 1573 ≈ 44.5% < 50%` → 被剔除。日志显示候选 60 只 → 仅 11 只通过，正是因为多数老转债在 2019~2025 间被强赎/到期，数据断崖导致覆盖度不足。这是"宁可少样本也不拿残缺数据造假"的保守处理。

### 3.3.2 幸存者偏差的具体表现

最终进入回测的 11 只转债，是"2019 年前上市、且到 2025 年仍有完整数据"的幸存者——中途被强赎、到期或退市的转债，要么被 `MIN_COVERAGE` 剔除、要么数据断档。结果是样本天然偏向"活下来且表现不差"的转债，双低策略的"债底保护"优势被样本选择放大。真实投资里你会持有到退市的那些"坏样本"，回测的 -9.83% 回撤大概率被低估。这是可转债（以及任何"当前列表"选股）回测的通病，引用结果时必须点明。

### 3.4 区间限制的原因

回测区间固定 `2019-01-01 ~ 2025-06-30`。原因：

- 可转债数据从 **2019 年前后才可靠**：更早的转债数量少、新浪接口覆盖差；
- 样本只含"活下来"的转债（没被强赎/退市的），存在**幸存者偏差**；
- 区间中途退市的转债持仓按最后成交价冻结（近似到期赎回），有小幅偏差。

### 3.5 `on_rebalance` 与索引方向

```python
d = self.getdatabyname(code)
if not self.live(d, cur):
    continue
price = d.close[0]                         # 当根收盘价（[0]=当根）
```

- `self.live(d, cur)` 过滤停牌/未上市转债（与 a02/a03/a04 同）。
- `d.close[0]` 取当根收盘价，list 语义的 `closes` 未在此用；全程无 Line 正索引，无未来函数。
- `prem = 0.0 if pd.isna(prem) else prem`：快照缺失时退化为纯低价排序，避免 NaN 污染。

### 3.6 `PanelStrategy` 与静态快照注入

`premium` 字典通过 `run_strategy(..., premium=premium)` 透传给策略 `params`（`('premium', None)`），`on_rebalance` 用 `self.p.premium` 读取。骨架负责月度调度与 `equal_weight_order` 整手调仓。

### 3.6.1 未建模的两个真实细节（诚实提示）

源码头部已声明两点简化，回测结果需打折理解：

- **T+0 未建模**：可转债实行 T+0，日内可反复交易；本策略按日线收盘调仓，无法刻画日内回转，换手率口径偏粗。
- **强赎条款未触发**：股价大涨触发"强制赎回"时，公司会按略高于面值的价格赎回，转债上涨空间被封顶（并非真"上不封顶"）。本策略不监控强赎进度，持仓可能恰好撞上强赎前的溢价率归零回撤。

这两点都会让真实双低的收益与回撤和本回测有偏差，引用 -9.83% 回撤时要心里有数。

## 四、与聚宽版的差异

| 维度 | 聚宽云端版 | backtrader 本地版 |
|------|-----------|-------------------|
| 可转债列表 | `get_all_securities(types=['cb'])`（全市场实时） | `listed_bonds(before, top)`（发行规模 Top60，上市早于 2019） |
| 溢价率 | 可查历史任意时点真实溢价率 | **仅当前快照**（`listed_bonds` 的 `premium`），静态不变 |
| 双低计算 | `价格 + 真实溢价率×100`（每日更新） | `价格 + 静态溢价率`（溢价率退化为常数） |
| 覆盖度检查 | 平台保证数据完整 | 手动 `MIN_COVERAGE >= 50%` 剔除残缺标的 |
| 回测区间 | 平台设置（2016~2026 量级的窗口） | 固定 2019-01-01 ~ 2025-06-30（数据可靠性限制） |
| 触发方式 | `run_monthly(rebalance, 1, time='09:30')` | `PanelStrategy` 的 `(年,月)` 变化检测 |
| 持有数量 | `bond_num=10` | `topn=5` |
| 下单口径 | `order_target_value(security, 市值)` | `equal_weight_order`（目标股数，整手） |
| 数据来源 | 聚宽可转债数据 | akshare 新浪转债日线 |

最核心差异是**溢价率的时效**：聚宽有历史真实溢价率，本地只有当前快照 → 本地版"双低"实为"单低（价格）+ 静态微调"。

## 五、回测结果（真实数据）

区间 **2019-01-02 ~ 2025-06-30（1573 个交易日）**，初始资金 100 万元，基准沪深300。数据来自 `results/logs/bt_a05_convertible_bond.log`。

> 注意：本策略区间（2019~2025）与其他 4 篇（多从 2010/2013/2015 起）**不同**，请勿横向直接比较累计收益。

| 指标 | 数值 |
|------|------|
| 累计收益率 | 42.28% |
| 年化收益率 | 5.81% |
| 基准累计收益率 | 32.55% |
| 超额收益 | 9.73% |
| 最大回撤 | -9.83% |
| 夏普比率 | 0.78 |
| 年化波动率 | 7.59% |
| 日胜率 | 52.15% |
| 总成交笔数 | 171 笔 |
| 累计换手率 | 2263.56% |

解读：可转债双低是 5 篇里**风险特征最好**的一篇——最大回撤仅 -9.83%、夏普 0.78（最高）、年化波动 7.59%（最低），印证了"债底保护"确实抗跌。但样本仅 11 只可用转债、区间受限，且溢价率是静态快照，收益有"结构幻觉"成分。超额 +9.73% 相对弱基准尚可，但绝不能据此推断"真实双低"也能如此——若用动态溢价率，结果可能不同。

## 六、改进方向（思考题）

1. **还原动态溢价率**：接入能回放历史转股溢价率的数据源（正股历史价 + 历史转股价自行计算 `溢价率 = 转债价/转股价值 - 1`），让"双低"真正每日更新，消除静态快照偏差。
2. **扩大样本与去幸存者偏差**：放宽 `MIN_COVERAGE`、纳入区间内上市/退市的转债（用最后成交价冻结近似），并把"当前上市"列表换成"区间时点"列表，减少幸存者偏差。
3. **三低 + 下修博弈**：在双低上加"剩余规模小"（小盘弹性大）与"可能触发转股价下修"的转债，提升股性弹性；并叠加 `buy_bracket` 止损，防止强赎前溢价率归零的回撤。
