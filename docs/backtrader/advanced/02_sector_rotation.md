## 二、心智模型：30+ 个行业，每月换一次队

```
每月第一个交易日（收盘后）
   │
   ├─ 1. 对每个申万一级行业指数，算最近 60 个交易日的涨幅
   ├─ 2. 排序，取最强的 5 个行业
   ├─ 3. 等权买入这 5 个"行业"（每个约 19.6% 仓位）
   └─ 4. 次日开盘成交
```

**和策略 2（个股动量）的结构完全一样**，只是把"股票"换成了"行业指数"：

| | 策略 2（个股动量） | 本篇（行业轮动） |
|---|---|---|
| 标的 | 40 只股票 | 31 个申万一级行业指数 |
| 因子 | 60 日涨幅 | 同一套 |
| 调度 | 月度 | 同一套 |
| 停牌/整手 | 需要处理 | **不需要**（指数不会停牌、也不用整手） |
| 可交易性 | 真实（买股票） | ⚠️ **不真实**（指数不可直接买卖） |

## 三、核心思路

**行业轮动（Sector Rotation）**：不同行业在不同经济阶段表现差异巨大。

| 经济阶段 | 历史常见表现 |
|---|---|
| 复苏（宽松、需求回暖） | 周期（有色、化工）、券商 |
| 过热（通胀上行） | 资源、能源 |
| 滞胀 | 必需消费、医药 |
| 衰退（宽松预期） | 债券、公用事业、银行 |

**策略的假设**：行业景气度（以及资金流入）有**延续性**，所以"近期强的行业"短期还会强。

**本策略的因子**：和动量一模一样——

$$Momentum_{industry} = \frac{Index_t}{Index_{t-60}} - 1$$

排序取最强 5 个，等权持有。

> **⚠️ 本篇最大的"不真实"（必须知道）**：
> **申万行业指数只是一个统计指数，你无法直接买卖它。** 本回测把"买行业指数"当成"买一个年费率≈0、跟踪误差≈0 的行业 ETF"，并假设它：
> 1. **不产生任何交易成本差异**（实际行业 ETF 有费率、买卖有冲击成本）；
> 2. **不对应现实中的可投资标的**（有些申万一级行业根本没有对应的 ETF，比如"轻工制造"）。
>
> 所以这一篇的正确读法是：**看"行业轮动这个想法有没有效果"，而不是把这串数字当实盘预期。** 想落地，需要换成行业 ETF 或行业成分股组合（那就是策略 2 的做法）。

## 四、算法结构

```
main()
 ├─ sw_industries()                      拿到 31 个申万一级行业（代码 + 名称）
 ├─ for 每个行业: load_sw_index(code)     拉行业指数日线（1999 年起）
 │      └─ 数据不足 LOOKBACK+1 根的 → 跳过
 ├─ data['__CAL__'] = 沪深300             日历源
 └─ run_strategy(SectorRotation, data, ...)
       │
       └─ SectorRotation.on_rebalance(cur)（每月）
             ├─ 遍历 tradables（这里是 31 个行业）
             ├─ live(d, cur) 且 closes[0] > 0
             ├─ 算 60 日涨幅
             ├─ 样本 < 5 → 不调仓
             └─ 取最强 5 个 → equal_weight_order()
```

## 五、代码逐段详解

### 5.1 参数

```python
TOPN = 5                    # 持有动量最强的几个行业
LOOKBACK = 60               # 行业动量回看期
START = '2010-01-01'        # 行业指数历史可回溯到 1999 年
```

### 5.2 策略类：和策略 2 几乎一样

```python
class SectorRotation(PanelStrategy):
    params = (('topn', TOPN), ('lookback', LOOKBACK), ('rebalance', 'monthly'),)

    def __init__(self):
        super().__init__()
        self.names = {d._name: d._name for d in self.tradables}   # 这里名字就是行业名

    def on_rebalance(self, cur):
        scores = {}
        for d in self.tradables:
            if not self.live(d, cur):
                continue
            closes = self.hist_close(d, self.p.lookback + 1)
            if closes is None or closes[0] <= 0:
                continue
            scores[d._name] = closes[-1] / closes[0] - 1.0        # 60 日涨幅
        if len(scores) < self.p.topn:
            return
        target = sorted(scores, key=scores.get, reverse=True)[:self.p.topn]
        self.equal_weight_order(target, cur)
```

**和策略 2 逐行对照**：除了 `self.names` 这一行（其实没被用到，属于冗余），**其余完全一样**——这就是 `PanelStrategy` 的价值：换标的、换因子都不用改骨架。

### 5.3 `main()`：31 个行业怎么装进引擎

```python
def main():
    sw = sw_industries()                     # 31 个申万一级行业
    data = {}
    for _, row in sw.iterrows():
        try:
            df = load_sw_index(row['code'], start=START, end=END)
            if len(df) >= LOOKBACK + 1:
                data[row['name']] = df       # ← 用"行业名"当数据源的名字
        except Exception as e:
            print(f'  [跳过] {row["name"]}: {str(e)[:50]}')

    data['__CAL__'] = load_daily(BENCHMARK, start=START, end=END)
    run_strategy(SectorRotation, data, cash=CASH, benchmark=BENCHMARK)
```

| 细节 | 为什么 |
|---|---|
| `data[row['name']]` | 用**行业名**（如"电子"）当数据源名字，调试时一眼看得懂 |
| `try/except` 逐个跳过 | 30+ 个行业里总有几个接口异常，不能让一个失败毁掉整次回测 |
| `if len(df) >= LOOKBACK + 1` | 数据太短的行业直接排除 |
| `data['__CAL__']` | 仍然需要日历源（第 10 章） |

## 八、回测结果怎么读

区间 2010-01 ~ 2026-09，初始 100 万，基准沪深300：

| 指标 | 数值 | 怎么理解 |
|---|---|---|
| 累计收益率 | **+79.72%** | 明显跑赢基准（+23.26%） |
| 年化收益率 | **+3.70%** | 绝对水平不高 |
| 最大回撤 | **−26.23%** | 优于纯个股动量（−49.75%） |
| 夏普比率 | **0.44** | 与个股动量（0.45）相当 |
| 成交笔数 | 408 | 月频，16 年多只换 400 次 |

**要点：**

1. **超额收益明显**（+79.72% vs +23.26%），说明"行业轮动"在 A 股这段历史里有效；
2. **回撤显著小于个股动量**：因为行业指数是**组合**，天然分散了个股风险；
3. **但要注意两条**：① 指数不可直接交易（见第三节）；② 年化只有 3.70%，绝对收益并不高。

## 九、易混点与常见错误

| 症状 | 原因 | 正确做法 |
|---|---|---|
| 以为可以直接买"申万电子指数" | 指数不可交易 | 落地要换成行业 ETF 或成分股 |
| 某个行业一直缺失 | 接口异常被 `try/except` 跳过 | 看日志里的"跳过"提示 |
| 收益算得过于乐观 | 指数回测隐含"零成本、零跟踪误差" | 明白这是上界；实盘要扣 ETF 费率与冲击成本 |
| 忘了 `__CAL__` | 多标的节拍错乱 | 仍然要加日历源 |

## 十一、改进方向（思考题）

1. **换成可交易标的**：把行业指数换成对应的行业 ETF（有 20+ 个申万一级行业有 ETF），观察收益衰减多少。
2. **加经济状态判断**：用 PMI、利率、信用利差等宏观变量做"该配哪些行业"的先验。
3. **行业内部的二次选股**：先选行业，再在每个行业内用策略 4/6 选个股（两层结构）。
4. **控制换手**：加"行业排名掉出前 10 才卖"的缓冲带。
