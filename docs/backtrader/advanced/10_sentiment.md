# 进阶策略 10：舆情情绪策略（量价情绪代理版）· backtrader 本地版

> 类型：另类数据 / 情绪分析（代理变量） ｜ 难度：★★★★★ ｜ 前置知识：PanelStrategy、量价特征构造、z-score 合成
> **运行框架：backtrader（本地回测 + 免费数据）** ｜ 本策略的**聚宽云端版**见 [docs/joinquant/advanced/10_sentiment.md](../../joinquant/advanced/10_sentiment.md)

> ⚠️ **重要声明（数据受限导致的替代）**：本策略的**原始思路是用股吧/新闻/研报文本做情感分析**（把文本转成「正面/负面」打分，作为选股因子）；但本地**没有免费可用的历史舆情文本数据**（新闻/股吧接口需付费权限），所以本 backtrader 版**改用「量价情绪代理因子」**——用市场行为反推情绪温度：量能异常（放量）、波动放大（振幅大）、隔夜跳空（信息冲击）。这**不是原始文本情绪的实现**，而是「当原始数据拿不到时，用量价代理变量近似」的通用做法（量化里极常见）。下文结论均指「量价代理版」，请勿等同于真实文本舆情。若要用真实舆情，需接入聚宽/研报 API 或自建爬虫 + NLP，因子接口可保持不变。

## 一、核心思路

情绪驱动的定价偏差：情绪温度高的股票短期更容易被追捧上涨。本地版用三个「情绪的足迹」合成情绪分，再与动量因子结合选股：

```
情绪代理因子：
    vol_ratio = 近 5 日均量 / 近 60 日均量        # 放量 = 关注度上升
    amp       = 近 5 日平均振幅 (high-low)/close   # 波动大 = 情绪激动
    gap       = 近 5 日 |开盘/昨收 - 1| 的均值     # 跳空 = 隔夜信息冲击
    情绪分    = z(vol_ratio) + z(amp) + z(gap)
    综合分    = z(情绪分) + z(20 日动量)
    选综合分最高的 K 只等权持有，每月调仓
```

为什么用这三个？情绪高涨时，往往伴随**放量**（更多人参与）、**波动放大**（多空博弈激烈）、**跳空**（隔夜出了大消息）。它们就是「情绪的足迹」——虽然拿不到文本，但这些可观测的量价特征能近似「关注度与情绪波动」。

给新手的直觉：你读不到股吧帖子，但你能看到「这只股票最近突然放量大涨、天天跳空」——这本身就是情绪升温的证据。代理变量思维：**原始数据拿不到，就用它的可观测后果来近似**。

## 二、算法结构（分步拆解）

```
每月第 1 个交易日触发 on_rebalance(cur)
   │
   ├─ 1. 逐标的算 _sentiment(d) → (vol_ratio, amp, gap)
   │      └─ 数据不足（< SHORT_WIN 或 < LONG_WIN）返回 None，跳过
   ├─ 2. 同时算 20 日动量 mom = closes[-1] / closes[0] - 1.0
   ├─ 3. 截面 z-score：
   │      sentiment = z(vol_ratio) + z(amp) + z(gap)
   │      score     = z(sentiment) + z(mom)
   └─ 4. 取综合分最高的 TOPN 只 → equal_weight_order(names, cur)
```

## 三、代码逐段详解 + backtrader 语法解析

### 3.1 `_sentiment` —— 三个情绪代理的构造（重点）

```python
closes = self.hist_close(d, self.p.lookback + 1)        # 21 个收盘价（list）
highs, lows = d.high.get(size=SHORT_WIN), d.low.get(size=SHORT_WIN)
opens, vols = d.open.get(size=SHORT_WIN), d.volume.get(size=LONG_WIN)
prev_close = closes[-(SHORT_WIN + 1):-1]                # 最近 5 天各自的「昨收」
amp  = float(np.mean([(highs[i] - lows[i]) / closes[-1] for i in range(SHORT_WIN)]))
gap  = float(np.mean([abs(opens[i] / prev_close[i] - 1.0) for i in range(SHORT_WIN)]))
vol_ratio = float(np.mean(vols[-SHORT_WIN:]) / (np.mean(vols) + 1e-9))
```

索引语义务必分清两种来源：

| 来源 | 写法 | 语义 |
|------|------|------|
| `hist_close` / `.get()` 返回 | `closes[-1]` | **list 最新一根**（当根） |
| backtrader Line | `d.close[0]` | Line 当根；`d.close[-1]` 是昨天 |

`closes` 是 `hist_close` 返回的 Python list，`closes[-1]` = 当根收盘、`closes[-(SHORT_WIN+1):-1]` = 切片取「倒数第 6 到倒数第 2」共 5 个值，即最近 5 天各自的昨收（与 `opens`/`highs`/`lows` 的 5 天一一对应）。

- **`amp`（振幅）**：用 `(high-low)/close[-1]` 算每日振幅，分母统一用当根收盘 `closes[-1]`，再对 5 天取均值。振幅大 = 当天多空拉锯激烈 = 情绪亢奋。
- **`gap`（跳空）**：`open / 昨收 - 1` 的绝对值，捕捉「隔夜出了消息导致开盘跳空」。5 天均值越大 = 隔夜信息冲击越频繁。
- **`vol_ratio`（量比）**：`vols` 来自 `d.volume.get(size=60)`（list），`vols[-5:]` 是最近 5 天量，除以全段 60 天均值 → 近期是否显著放量。放量 = 关注度上升。

三者都先 `zscore` 再相加，合成「情绪温度」——量价维度一致偏高才打高分。

### 3.2 截面 z-score 合成与动量结合

```python
df = pd.DataFrame(rows).T
sentiment = (zscore(df['vol_ratio']) + zscore(df['amp']) + zscore(df['gap']))
score = zscore(sentiment) + zscore(df['mom'])
names = score.sort_values(ascending=False).index[:self.p.topn].tolist()
self.equal_weight_order(names, cur)
```

`zscore` 在「当期截面」上标准化，消除量纲后相加。`score = z(情绪) + z(动量)` 把情绪因子和动量因子并列——情绪高可能继续涨（追涨），也可能已过热（反转），所以**不与动量单独使用**，而是叠加，让「高情绪 + 强动量」的股票优先。最后取综合分最高的 TOPN 只等权买入。

### 3.3 防未来函数检查

`_sentiment` 用的 `closes`/`highs`/`lows`/`opens`/`vols` 全部来自 `hist_close` 和 `.get(size=...)`，这些都是「截至当根及之前」的已知数据，`closes[-1]` 是当根（非未来）。`prev_close` 用 `closes[-6:-1]` 也是历史值。没有用到 `line[1]`（未来），符合 base doc 5.1 的索引纪律。

### 3.4 关键参数表

| 参数 | 默认 | 含义 |
|------|------|------|
| `UNIVERSE_SIZE` | 40 | 沪深300 前 40 只（幸存者偏差） |
| `TOPN` | 10 | 持有股票数 |
| `LOOKBACK` | 20 | 动量回看期 |
| `SHORT_WIN` | 5 | 情绪观测窗口（短） |
| `LONG_WIN` | 60 | 量比基准窗口（长） |

### 3.5 backtrader 索引方向速查（防未来函数，必记）

| 写法 | 含义 | 能否在回测中用 |
|------|------|----------------|
| `d.close[0]` | 当根收盘价（Line 索引） | ✅ |
| `d.close[-1]` | 上一根（昨天） | ✅ |
| `d.close[-2]` | 上上根（前天） | ✅ |
| `d.close[1]` | 下一根（明天） | ❌ 未来数据，禁用 |
| `d.close.get(size=n)` 返回的 list | `list[0]`=最旧、`list[-1]`=最新 | ✅（list 语义，与 Line 相反） |

本策略 `closes`/`highs`/`lows`/`opens`/`vols` 全部来自 `hist_close` 和 `.get(size=...)` 返回的 list，`closes[-1]`=当根、`closes[-6:-1]`=最近 5 天昨收（与 5 天 open 一一对应）。`prev_close` 用历史切片、不含未来。两个易错点：**(1)** `line[1]` 是未来，禁用；**(2)** 首根 K 线 `[-1]` 会绕到数据集末尾（base doc 5.1），靠 `hist_close` 的 `len(d)<n` 判空挡住。

### 3.6 代理变量思维：当原始数据拿不到时怎么办

量化里最实用的工程思维之一：**原始数据（文本舆情）拿不到，就用它的「可观测后果」近似**。情绪升温时，市场行为会留下足迹——放量（更多人参与）、波动放大（多空拉锯）、跳空（隔夜出消息）。这三个量价特征就是「情绪的代理」。代理变量不完美（噪声大、方向模糊），但比「完全不用情绪」更接近真实——这是本地版在免费数据约束下的务实选择。

### 3.7 三个代理因子各自的局限

- **`vol_ratio`（量比）**：放量可能是情绪升温，也可能是主力出货；单看量比易误判。
- **`amp`（振幅）**：高振幅 = 情绪亢奋，但也可能是流动性差的妖股在瞎炒。
- **`gap`（跳空）**：跳空 = 隔夜信息冲击，但 A 股有涨跌停，极端跳空往往发生在利空跌停，反而是风险信号。

三者 z-score 后相加，靠「截面一致偏高」降低单因子的误判——只有量、波、跳空同时异常，才打高情绪分。这也是为什么 `score = z(情绪) + z(动量)`：用动量做二阶确认，避免纯情绪追高接盘。

### 3.8 回测时序与情绪因子常见坑

`on_rebalance(cur)` 在当根收盘后调用（月度），`self.buy/sell` 默认**下一根开盘**成交（base doc 5.6），天然防未来。情绪因子坑：(1) **方向模糊**——高情绪可能继续涨（追涨），也可能已过热（反转），所以必须与动量结合而非单独用；(2) **代理噪声**——量价代理对情绪的近似能力有限，回测夏普仅 0.46（见第五节）；(3) **幸存者偏差**——`load_index_members` 返回当前成分，回测用了历史并不存在的龙头。

### 3.9 与 a08（ML 因子）的对比定位

a08 用 6 个量价+基本面因子训模型预测收益，夏普 0.98；本策略用 3 个量价情绪代理 + 动量，夏普 0.46。两者都属「另类/量价」维度，但 a08 的 ML 合成表达了更复杂的非线性，本策略的代理更接近「动量 + 放量」变体。若换成真实文本舆情，本策略 alpha 可能变化，但本地无法验证——切勿把价量代理当成真实情绪结论。

### 3.10 一个完整例子：某月情绪打分

假设某调仓日 3 只股票的代理值：A（vol_ratio=2.1, amp=0.04, gap=0.02）、B（vol_ratio=1.2, amp=0.02, gap=0.01）、C（vol_ratio=0.8, amp=0.015, gap=0.005）。截面 z-score 后 A 情绪分最高、C 最低；若三者动量相近，则 A 综合分最高、优先入选。注意：若 A 的跳空来自利空跌停（gap 大但方向为负），纯量价代理**无法区分「利好跳空」与「利空跳空」**——这是代理变量的固有盲区，只有真实文本舆情才能区分多空语义。

## 四、与聚宽版的差异

| 维度 | 聚宽版 a10 | backtrader 本地版 |
|------|-----------|-------------------|
| 情绪来源 | 新闻/研报文本情感词典（`get_news`/机构评级） | **量价情绪代理**（量比/振幅/跳空 z 合成） |
| 文本数据 | 需新闻接口权限（其 `get_sentiment` 也是价量代理桩） | 无免费文本 → 纯价量代理 |
| 因子合成 | 情绪分排序选股 | `z(情绪) + z(动量)` 合成 |
| 触发方式 | `run_monthly(rebalance, 1)` | `PanelStrategy` 月度 `on_rebalance` |
| 下单口径 | `order_target_value` | `equal_weight_order` → `round_lot` 整手 |
| 费用/滑点 | `set_order_cost(type='stock')` + `FixedSlippage(0.02)` | `AStockCommission` + `set_slippage_perc(0.0002)` |
| 数据可得性 | 云端可接新闻文本 | **无免费新闻文本 → 改量价代理（本例特有）** |

**数据可得性差异（本例特有，必须知道）**：聚宽版文档描述的是「文本情感分析」，但其实现里的 `get_sentiment` 也退化成了「涨幅 + 成交额趋势」的价量代理（新闻接口需权限）。所以**两个版本本质上都是「代理」**，区别只是代理的构成：聚宽用 `ret + 0.5*money_trend`（含成交额），本地用「量比 + 振幅 + 跳空」三因子（无成交额字段，纯价量）。本地版更彻底地体现了「代理变量思维」——但都**不是真实文本舆情**，切勿把价量代理当成真实情绪 alpha。

> 幸存者偏差提示：同 a07/a08，`load_index_members` 返回当前成分，回测用了历史并不存在的「当前龙头」。

| 年化波动率 | 27.94% |

| 超额收益 | 156.99% |

解读：量价情绪代理策略累计 176.65%、夏普 0.46，是 5 篇里最弱的（收益最低、夏普最低），最大回撤 -49.17% 也偏高。这提示「量比+振幅+跳空」代理的 alpha 有限——它本质接近「动量 + 放量」的变体，且情绪因子方向模糊（高情绪可能追高接盘）。若换成真实文本舆情，结论可能不同，但本地无法验证。对比 a08（夏普 0.98），说明「可观测量价」对情绪的近似能力有限。

## 六、改进方向（思考题）

1. **接入真实文本数据**：用聚宽新闻接口 / Tushare 新闻，做真词典法或 BERT 情感分析，验证文本情绪是否真有增量 alpha。
2. **情绪拐点而非水平**：测「情绪的边际变化」（从冷转暖）可能比「情绪高低」更有效，避免追高过热股。
3. **代理因子升级**：把量比/振幅/跳空换成更稳健的「异常换手」「大单净流入」等，或加个股止损压低 -49% 回撤；若能拿到分钟/新闻数据，应按原始思路升级回文本舆情版。
