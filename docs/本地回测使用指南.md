# 本地回测使用指南（v3.1.0）

> 本指南教你如何在本机 PyCharm 中**一键回测**仓库里的 20 个策略，无需再复制粘贴到聚宽网页。

---

## 一、背景：为什么能在本地回测

聚宽官方只提供两类能力：

1. **`jqdatasdk`**：官方数据 SDK，能在本地拉取真实的行情、财务数据（需注册账号）；
2. **云端回测**：`initialize`/`run_daily` 这套回测引擎只能在聚宽网页运行，**不开放本地独立运行**。

因此，本仓库自研了一个轻量级回测引擎 **`jqbt`**（JoinQuant BackTest），它：

- **封装聚宽风格 API**（`initialize`/`run_daily`/`attribute_history`/`get_fundamentals`/`order_target_value` 等），让你的策略代码**几乎不用改**就能本地运行；
- **底层接 `jqdatasdk`** 拉取真实数据（行情、财务、成分股、行业等）；
- **内置撮合、手续费、滑点、做空、绩效统计、可视化**。

> 一句话：**`jqdatasdk` 负责"取数"，`jqbt` 负责"把数据串成回测"**。

## 二、环境准备（PyCharm + 虚拟环境）

### 2.1 安装 Python

建议 Python 3.9～3.13（`jqdatasdk` 已在 3.13 实测安装成功；3.9～3.11 兼容性最稳）。
**必须用真实安装的 Python**（python.org 安装包，或本机已有的托管版），不要用微软商店的别名。

### 2.2 在 PyCharm 中创建虚拟环境

1. 打开本仓库目录作为 PyCharm 项目；
2. `File → Settings → Project → Python Interpreter` → 点击齿轮 → `Add Interpreter`；
3. 选择 **Virtualenv Environment**（新建，位置随意，如 `.venv`），Base interpreter 选你的 Python 3.9+；
4. 点击 OK，等待虚拟环境创建完成。

> 虚拟环境的好处：依赖隔离，不污染系统 Python；换机器可一键重建。

> ⚠️ **选择 Base interpreter 时的一个大坑**：不要选 `C:\Users\<用户名>\AppData\Local\Microsoft\WindowsApps\python3.xx.exe`！
> 这是微软商店的「应用执行别名」（0 字节空壳，不是真 Python），选它必报
> `CreateProcess error=1920, 系统无法访问此文件`。
> 正确做法：点文件夹图标浏览，选一个**真实安装**的 `python.exe`（见下），或先从 python.org 安装。

**本机可直接使用的真实 Python 路径示例**（选它作为 Base interpreter 即可）：

```
C:\Users\攀泊桓\.workbuddy\binaries\python\versions\3.13.12\python.exe
```

（Python 3.13.14，已验证可用；若你自己从 python.org 装了 Python，用你的安装路径同样可以）

### 2.3 安装依赖

在 PyCharm 底部打开 **Terminal**（会自动激活虚拟环境），执行：

```bash
pip install -r requirements.txt
```

核心依赖会装上：`jqdatasdk`、`pandas`、`numpy`、`matplotlib`、`scikit-learn`、`statsmodels`。

> 若安装慢，可加国内镜像：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 2.4 配置聚宽账号

本地取数必须有一个聚宽账号（免费注册，每月有数据额度）。

1. 注册：https://www.joinquant.com ；
2. 把根目录的 `config.example.py` **复制一份改名为 `config.py`**，然后填写：
   ```python
   JQDATA_PHONE = "你的手机号"
   JQDATA_PASSWORD = "你的密码"
   ```
   （`config.py` 含真实密码，已被 `.gitignore` 忽略、不会提交到 GitHub；仓库里只提供不含密码的 `config.example.py` 模板）
3. （可选）或设置环境变量 `JQDATA_PHONE` / `JQDATA_PASSWORD`，代码会优先读环境变量。

> `config.py` 已在 `.gitignore` 中忽略，不会把密码提交到 GitHub。

## 三、一键回测

打开任意策略文件（如 `strategies/beginner/s01_ma_cross.py`），直接**右键 → Run**（或点运行按钮）。

脚本会：

1. 登录聚宽数据；
2. 按文件顶部参数回测；
3. 打印详细绩效报告（年化收益、最大回撤、夏普、胜率、换手率等）；
4. 保存净值曲线 + 回撤曲线图（`s01_ma_cross_result.png`）。

### 3.1 修改回测参数

每个策略文件顶部都有可修改的参数：

```python
START_DATE   = '2016-01-01'   # 回测开始日期
END_DATE     = '2024-01-01'   # 回测结束日期
INITIAL_CASH = 1000000        # 初始资金（元）
BENCHMARK    = '000300.XSHG'  # 基准指数
```

策略自身的参数（如均线周期、持仓数量）在 `initialize(context)` 里，通过 `g.xxx` 修改。

### 3.2 调试数据

回测时想看中间数据，直接 `print` 或 `log.info(...)` 即可，输出会实时打印到控制台。

## 四、回测结果说明

回测结束会输出如下绩效报告：

| 指标 | 含义 |
|------|------|
| 累计收益率 | 期末资产相对初始资金的涨跌幅 |
| 年化收益率 | 按 252 个交易日折算的年化收益 |
| 基准累计收益率 | 同期基准（沪深300）的涨跌幅 |
| 最大回撤 | 净值从峰值到谷底的最大跌幅 |
| 夏普比率 | 风险调整后收益（越高越好） |
| 年化波动率 | 收益的波动程度 |
| 日胜率 | 上涨交易日占比 |
| 换手率 | 累计买入金额 / 平均资产 |

同时生成两张图：
- **净值曲线**：策略净值 vs 基准净值；
- **回撤曲线**：随时间变化的回撤。

## 五、引擎能力与限制（务必阅读）

### 5.1 已支持

- `initialize` / `run_daily` / `run_weekly` / `run_monthly` 定时调度；
- `attribute_history` / `get_price` / `history` / `get_bars` 行情；
- `get_index_stocks` / `get_all_securities` / `get_industry` / `get_industry_stocks` / `get_industries` 标的池与行业；
- `query` / `get_fundamentals` / `valuation` / `indicator` / `income` / `balance` / `cashflow` 财务数据；
- `get_current_data`（ST / 停牌 / 涨跌停 过滤）、`get_security_info`；
- `order` / `order_value` / `order_target` / `order_target_value` 下单（含**做空**）；
- 手续费、滑点、印花税、最低佣金；
- 绩效统计与可视化。

### 5.2 近似与限制（重要）

| 项 | 本地引擎的处理 | 说明 |
|----|--------------|------|
| 当日实时状态（is_st/paused/涨跌停） | 用历史行情 + 证券名称**近似** | 涨跌停价用前收盘 ±10% 近似，ST 用名称判断，停牌用"无成交"判断，**非精确** |
| 分钟级策略（a09） | 降级为**日级近似** | 真正的分钟级回测需在聚宽云端用 `frequency='minute'` |
| 复权 | 默认前复权 `fq='pre'` | 与聚宽一致 |
| 撮合 | 按当日收盘价成交 | 未模拟盘中撮合、涨跌停排队、成交量约束 |
| 停牌 | 近似处理 | 真实聚宽云端会精确处理停复牌 |

### 5.3 免费额度注意

聚宽免费账号每月有数据额度限制。回测**全市场 + 10 年**数据可能超额度，建议：

- 先用 **2～3 年短区间**验证跑通；
- 选股策略优先用**指数成分股**（如沪深300）而非全市场；
- 需要更长时间/更大范围时，可升级聚宽会员。

## 六、常见问题（FAQ）

**Q1：运行报 `RuntimeError: 未提供聚宽账号`？**
→ 没配置账号，见 2.4 节。**新克隆仓库的话**，根目录没有 `config.py`（含密码不入库），需要先把 `config.example.py` 复制一份改名为 `config.py` 再填账号。

**Q2：报 `jqdatasdk` 安装失败 / 导入报错？**
→ 确认虚拟环境已激活、`pip install -r requirements.txt` 成功；Python 版本建议 3.9～3.11。

**Q2.5：建虚拟环境报 `Cannot run program "...WindowsApps\python3.13.exe": CreateProcess error=1920`？**
→ PyCharm 选中的是**微软商店的 Python 假解释器**（应用执行别名，0 字节空壳），不是真 Python。
两种修复任选：
- **推荐**：删除当前 venv，重新 `Add Interpreter → Virtualenv Environment → New`，Base interpreter 点文件夹图标浏览到真实 `python.exe`（如 `C:\Users\攀泊桓\.workbuddy\binaries\python\versions\3.13.12\python.exe` 或 python.org 安装的路径）；
- 或者关闭商店别名：`Windows 设置 → 应用 → 高级应用设置 → 应用执行别名`，把 `python.exe` / `python3.exe` 两项关掉，再从 python.org 安装正式版 Python。

**Q3：回测很慢？**
→ 引擎对行情做了内存缓存；首次拉取较慢，重复回测会快很多。可缩小回测区间或股票池。

**Q4：成交笔数为 0？**
→ 多为股票池过滤后无可用标的，或因子数据不足。检查 `log` 输出，或缩短过滤条件。

**Q5：想用真实数据但没账号，能先跑通吗？**
→ 可以。引擎核心逻辑已用离线模拟数据验证通过（`_verify_all.py`），但**真实回测必须联网 + 有账号**。
