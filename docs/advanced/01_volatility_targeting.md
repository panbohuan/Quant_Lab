# 进阶策略 1：波动率目标策略（Volatility Targeting）

> 类型：风险控制 / 仓位管理 ｜ 难度：★★★★☆

## 一、核心思路

前面入门篇的 10 个策略，核心都是在回答「**选什么股票**」；而波动率目标策略第一次把问题切换到「**该买多少仓位**」。

想象你在开车：平坦的高速路上你可以开快一点（仓位重一点），但到了弯道多、路面湿滑的山路，你自然会减速（减仓）。波动率目标策略就是给组合装一个「自动驾驶的油门控制器」：

- **市场波动率低**（路况好）→ 加仓，多暴露风险去博收益；
- **市场波动率高**（路况差）→ 减仓，保住本金别翻车。

它的目标不是预测涨跌，而是把组合的波动率**稳定在一个目标水平**（比如年化 15%）。这就是「风险预算」思想——先决定「我愿意承担多少风险」，再反过来算「应该买多少仓位」。

## 二、算法结构

```
每周第1个交易日 → rebalance
  ├─ 取标的过去 N 日收盘价
  ├─ 算日收益率序列
  ├─ 年化波动率 = std(日收益率) × √252
  ├─ 目标仓位 = 目标波动率 / 当前波动率（封顶、封底）
  └─ order_target_value 调整到目标市值
```

## 三、函数详解

### 3.1 `attribute_history` —— 取历史行情

**算法逻辑**：获取单个标的过去 N 个交易日的行情，返回 DataFrame（时间索引）。

**基本用法**：

```python
df = attribute_history('000300.XSHG', 61, '1d', 'close', df=True)
closes = df['close']          # 一个 pandas Series
```

**参数说明**：

| 参数 | 含义 |
|------|------|
| `security` | 单个标的代码（只能传一个） |
| `count` | 往回取多少个交易日 |
| `unit` | 时间单位，`'1d'` 为日线 |
| `fields` | 字段，如 `'close'`、`['open','close']` |
| `df` | `True` 返回 DataFrame，`False` 返回 dict |

> 为什么这里传 `lookback + 1` 根？因为要算出 `lookback` 个「收益率」，而收益率需要「相邻两天的价格相除」，多取 1 根才能得到完整的收益率序列。

### 3.2 `numpy.std` —— 标准差（波动率的数学本质）

**算法逻辑**：标准差衡量一组数据偏离其平均值的程度。在金融里，收益率的标准差就是「波动率」的度量——标准差越大，说明价格上蹿下跳越厉害。

**其他用法**：

```python
import numpy as np
rets = [0.01, -0.02, 0.015, -0.005]
vol_daily = np.std(rets)              # 日波动率
vol_annual = vol_daily * np.sqrt(252) # 年化：×√252
```

### 3.3 `order_target_value` —— 按目标市值调仓

**算法逻辑**：把某标的的持仓市值调整到「目标金额」。如果当前市值低于目标就买入补足，高于目标就卖出多余。

**基本用法**：

```python
# 把沪深300的持仓调整到 50 万元
order_target_value('000300.XSHG', 500000)

# 清仓：目标市值设为 0
order_target_value('000300.XSHG', 0)
```

**与其他下单函数的区别**：

| 函数 | 含义 |
|------|------|
| `order_value(s, x)` | 买入 x 元（只在买入时用） |
| `order_target_value(s, x)` | 调整到 x 元（自动买卖） |
| `order(s, n)` | 买入 n 股 |
| `order_target(s, n)` | 调整到 n 股 |

> 波动率目标策略用 `order_target_value` 最合适，因为它需要「每天把仓位调到一个新目标」，而不是单纯的买或卖。

## 四、核心概念详解（面向新手）

### 4.1 什么是「波动率」？

波动率就是**价格波动的剧烈程度**。你可以把它想象成「股票的脾气」：

- 银行股、公用事业股：波动率低，像温吞水，每天涨跌 0.5% 上下；
- 科技股、次新股：波动率高，像坐过山车，一天涨跌 3%~5% 是常事。

数学上，波动率 = 收益率的标准差。年化波动率 15% 意味着：这只标的「大概率」一年内的涨跌幅在 ±15% 这个范围内（更严格说是 ±15% 覆盖约 68% 的情况，符合正态分布假设）。

### 4.2 为什么波动率能辅助决策？

因为波动率直接对应**风险**。金融学有一条铁律：**风险和收益通常是一对孪生兄弟**。你想赚得多，往往就得承担更大的波动。

波动率目标策略的思路是反过来——**先定风险，再定仓位**：

```
目标仓位 = 目标波动率 ÷ 当前波动率
```

- 当前波动率 30%，目标 15% → 仓位 = 0.5（半仓）
- 当前波动率 10%，目标 15% → 仓位 = 1.0（满仓，但被上限拦住）

这样做的好处是：**牛市加仓、熊市减仓是自动发生的**。因为牛市初期往往波动率低（市场平静），此时仓位自动加重；而大跌前波动率往往会先放大，仓位自动减轻。这本质上是一个「内置的风控开关」。

### 4.3 几个常见的坑

1. **波动率是滞后的**：它基于「过去 N 天」算出来的，所以对「黑天鹅」这类突发暴跌反应会慢半拍。这是所有波动率模型的固有缺陷。
2. **杠杆的双刃剑**：如果放开 `max_weight` 上限（允许 >1），波动率目标策略会在低波动时自动加杠杆。低波动加杠杆是很多「风险平价」基金爆仓的根源——因为「低波动」不等于「没风险」，一旦波动突然放大，高杠杆会加速亏损。
3. **波动率≠回撤**：波动率衡量的是「日常震荡」，最大回撤衡量的是「最深的一次下跌」。两者相关但不相等。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01（约 10 年）
- **初始资金**：100 万元
- **基准**：沪深300
- **标的**：沪深300指数（可换成 ETF 更接近实盘）

**重点观察**：对比「满仓持有沪深300」与「波动率目标策略」，重点看**最大回撤**是否显著降低、**夏普比率**是否提高。波动率目标策略的收益不一定更高，但通常风险调整后收益（夏普）更好——这正是它的价值所在。

## 六、改进方向

1. **多资产**：把单一指数扩展到股票+债券+商品，做真正的风险预算配置；
2. **更快的波动率估计**：用 EWMA（指数加权）替代简单标准差，对近期波动更敏感；
3. **下行波动率**：只算「下跌日」的波动率，更关注风险而非整体波动；
4. **结合趋势**：波动率控制仓位 + 均线判断方向，双保险。
