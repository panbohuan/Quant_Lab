# 进阶策略 7：因子择时策略（Factor Timing）

> 类型：因子进阶 / 动态多因子 ｜ 难度：★★★★★

## 一、核心思路

入门篇的策略 7（四因子打分）用的是「**静态权重**」——每个因子的权重固定不变（比如动量 40%、估值 30%、质量 30%）。因子择时策略升级为「**动态权重**」——根据市场环境，让权重「随行就市」。

核心认知：**因子也有周期**。没有一个因子永远有效：

- **动量因子**：在趋势明显的市场（牛市、单边行情）里很灵，但在震荡市里会被反复打脸（追高就套）；
- **价值因子**（低估值）：在熊市、价值回归时抗跌，但在牛市里「便宜的更便宜」，跑输成长；
- **质量因子**（高ROE）：在风险偏好低、追求确定性的环境里受追捧，在炒题材的狂热期被冷落。

因子择时就是**判断当前是什么环境，然后超配「在这个环境里最吃香」的因子**。

## 二、算法结构

```
每月第1个交易日 → rebalance
  ├─ 用市场波动率判断当前"环境状态"
  │   高波动 → risk-on（超配动量）
  │   低波动 → risk-off（超配质量）
  │   中等   → neutral（均衡）
  ├─ 计算各股票的动量/估值/质量因子
  ├─ 因子排名百分位（统一量纲）
  ├─ 按动态权重加权合成综合分
  └─ 按综合分取前 N 只
```

## 三、函数详解

### 3.1 `rank(pct=True)` —— 排名百分位（统一量纲）

**算法逻辑**：这是因子合成里最实用的一招。不同因子的量纲天差地别（PE 是几十倍、ROE 是百分之几、动量是 ±0.3），不能直接相加。排名百分位把每个因子都映射到 0~1 区间（1 = 最好），这样就能公平加权。

**基本用法**：

```python
import pandas as pd
s = pd.Series([10, 20, 30, 40], index=['A', 'B', 'C', 'D'])
# 值越大越好：rank 升序后转百分位
s.rank(pct=True)  # A=0.25, B=0.5, C=0.75, D=1.0
# 值越小越好：加 ascending=False
s.rank(pct=True, ascending=False)  # A=1.0, D=0.25
```

**为什么用百分位而不是 z-score？** 两者都行，但百分位更「抗异常值」——即使某只股票 PE 高达 5000 倍（异常值），它也只是排到最后一名（0），不会像 z-score 那样把整个分布带偏。

### 3.2 `np.std` —— 波动率判断环境

与进阶策略1一致：用沪深300的波动率作为「市场情绪的体温计」，判断当前是 risk-on 还是 risk-off。

### 3.3 动态权重的实现

**算法逻辑**：用一个函数返回「当前环境对应的权重字典」，然后加权合成时直接用这个字典。

```python
weights = detect_market_regime(context)  # 返回 {'momentum':0.6, 'value':0.15, 'quality':0.25}
score = (weights['momentum'] * mom_pct +
         weights['value'] * pe_pct +

```

## 四、核心概念详解（面向新手）

### 4.1 什么是「因子周期」？

因子就像「季节」：夏天穿短袖（动量）、冬天穿棉袄（质量）。如果你一年四季都穿短袖，冬天就会挨冻——这就是「静态因子」的缺陷。

因子的有效性与市场环境强相关：

| 市场环境 | 有效因子 | 逻辑 |
|----------|----------|------|
| 牛市/趋势市 | 动量、成长 | 强者恒强，追涨有效 |
| 熊市/避险市 | 质量、低波动 | 好公司抗跌 |
| 价值回归市 | 价值（低估值） | 便宜的补涨 |
| 震荡市 | 反转、低波 | 涨多了跌、跌多了涨 |

因子择时就是「看天气穿衣服」——先判断季节（市场环境），再选合适的衣服（因子权重）。

### 4.2 怎么判断「市场环境」？

本策略用「**波动率**」作为最简代理：

- **高波动 = risk-on**：市场活跃、趋势强，动量因子吃香；
- **低波动 = risk-off**：市场谨慎、追求确定性，质量因子吃香。

更高级的做法会引入更多指标：

- **估值分位**：市场整体 PE 处在历史什么位置（贵了要谨慎）；
- **宏观数据**：GDP、PMI、利率、社融（经济好不好）；
- **市场情绪**：换手率、融资余额、北向资金（资金热不热）。

### 4.3 因子择时的坑

1. **环境判断也是滞后的**：波动率、估值分位都是「事后」算的，判断「当前环境」本身就有误差；
2. **过度拟合环境状态**：如果把环境分得太细（比如 10 种状态），每个状态的样本太少，权重设置纯属「拍脑袋」，很容易过拟合；
3. **权重切换的冲击**：环境切换时权重突变，导致频繁换仓、成本飙升；
4. **因子择时≠保证赚钱**：环境判断错了，动态权重可能比静态权重还差。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：对比「静态四因子打分」（入门篇策略7）和「因子择时」（本策略），看动态权重能否在**特定年份**（如 2018 熊市、2020 成长牛市、2021 周期年）跑赢静态权重。同时观察：如果动态权重反而跑输，说明环境判断逻辑需要改进——这也是学习的价值所在。

## 六、改进方向

1. **更丰富的环境指标**：加入估值分位、宏观数据、情绪指标，构建「环境打分模型」；
2. **平滑权重切换**：用移动平均或阈值缓冲，避免权重突变；
3. **因子拥挤度**：监测因子的「拥挤度」（多少人用同一因子），拥挤时降低权重；
4. **机器学习判断环境**：用分类模型预测「当前是哪种市场状态」。
