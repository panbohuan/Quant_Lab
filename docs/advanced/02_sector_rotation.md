# 进阶策略 2：行业轮动策略（Sector Rotation）

> 类型：中观配置 / 行业轮动 ｜ 难度：★★★★☆

## 一、核心思路

入门篇的策略都是「**自下而上**」（直接在全市场挑股票），而行业轮动是「**自上而下**」：先判断「哪个行业现在最强势」，再在这个行业里挑股票。

这就像选餐厅：自下而上是「在整条美食街里一家家挑」，自上而下是「先看今天哪类菜系最火（比如川菜），再在川菜馆里挑」。

行业轮动背后有一条经济学逻辑：**经济周期会轮番利好不同行业**。

- 经济复苏期 → 周期股（有色、钢铁、化工）先涨；
- 经济过热期 → 消费、科技接力；
- 经济衰退期 → 防御性行业（医药、公用事业）抗跌。

策略用「行业动量」作为代理指标——**过去一段时间涨得最猛的行业，短期倾向于继续跑赢**（动量效应在行业层面比个股层面更稳定）。

## 二、算法结构

```
每月第1个交易日 → rebalance
  ├─ get_industries('sw_l1') 获取申万一级行业
  ├─ 算每个行业指数过去 N 日动量
  ├─ 选动量最强的 top_n 个行业
  ├─ 取这些行业的成分股
  ├─ 过滤 + 个股动量选股
  └─ 等权买入
```

## 三、函数详解

### 3.1 `get_industries` —— 获取行业列表

**算法逻辑**：返回指定行业分类体系下的全部行业。`name='sw_l1'` 表示申万一级行业（共 31 个，如银行、医药生物、食品饮料等）。

**基本用法**：

```python
industries = get_industries(name='sw_l1', date='2024-01-01')
print(industries.index.tolist())   # 行业代码列表，如 ['801010', '801020', ...]
```

**返回值**：DataFrame，索引是行业代码，包含 `name`（行业名）、`index_code`（行业指数代码，如 `801010.SI`）等列。

> 关键：行业动量是用「行业指数」（`.SI` 结尾）的涨跌幅来衡量的，不是用成分股平均。所以要从 `index_code` 列取行业指数代码。

### 3.2 `get_industry_stocks` —— 获取行业成分股

**算法逻辑**：返回某行业在某交易日的成分股列表。

**基本用法**：

```python
bank_stocks = get_industry_stocks('801780', date='2024-01-01')  # 银行行业
print(bank_stocks)   # ['000001.XSHE', '600000.XSHG', ...]
```

### 3.3 `get_industry` —— 反查个股所属行业（补充）

**算法逻辑**：查询一只股票在某个日期属于哪个行业。

**基本用法**：

```python
info = get_industry('000001.XSHE', date='2024-01-01')
# 返回 {'sw_l1': {'industry_code': '801780', 'industry_name': '银行'}}
```

> 注意区分：`get_industries`（复数，返回行业列表）、`get_industry`（单数，返回个股所属行业）、`get_industry_stocks`（返回行业的成分股）。三个函数名字像但用途完全不同。

## 四、核心概念详解（面向新手）

### 4.1 什么是「申万一级行业」？

申万（申银万国）是一家证券公司，它把 A 股所有上市公司按主营业务分成若干行业，形成了一套行业分类标准。「一级行业」是最粗的分类，共 31 个，比如：银行、非银金融、医药生物、食品饮料、电子、计算机、有色金属、钢铁……

这套分类的意义在于：**同一行业的公司，经营受相同的宏观因素驱动，股价走势往往高度相关**。比如央行降息利好银行和地产，锂价上涨利好有色板块。所以「按行业」比「按个股」更能捕捉系统性机会。

### 4.2 为什么行业有轮动？

核心是**经济周期 + 资金偏好**：

1. **经济周期**：不同行业对经济周期的敏感度不同。复苏期周期股先涨（需求回暖），衰退期防御股抗跌（需求刚性）。
2. **资金偏好**：市场资金是有限的，会像水流一样从一个板块流向另一个「性价比更高」的板块。当科技股涨太多、估值太高，资金就会流向还没涨的板块。
3. **政策驱动**：行业政策（如新能源补贴、地产调控）会直接改变一个行业的景气度。

行业轮动策略就是试图**骑在资金流动的浪头上**——买正在被资金追捧的行业。

### 4.3 行业动量的优势与陷阱

**优势**：行业动量比个股动量更「稳」。个股容易因突发事件暴涨暴跌，但一个行业整体的趋势更平滑、更持久。

**陷阱**：
1. **拥挤交易**：当一个行业动量太强、人人都追进去时，往往已经接近顶部（买在最高点）。
2. **风格切换**：市场风格（大盘/小盘、成长/价值）切换时，行业动量可能突然失效。
3. **行业指数滞后**：行业指数是成分股加权算的，如果用的是滞后的成分股名单，会有偏差。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：对比「行业轮动」与「全市场动量选股」，看行业轮动是否能在**降低换手率**的同时保持收益。同时注意观察：在 2017（白马蓝筹）、2020（成长科技）、2021（周期资源）等不同风格年份，行业轮动的表现差异——这能帮你理解「行业动量何时有效、何时失效」。

## 六、改进方向

1. **多指标轮动**：不只靠动量，加入行业估值分位、景气度（盈利增速）等；
2. **行业中性**：在行业内选股时做市值/行业中性，剔除行业 beta 的干扰；
3. **控制行业集中度**：限制单个行业最大权重，避免押注单一行业；
4. **动量反转结合**：短期反转（1个月）+ 中期动量（3-12个月）双信号。
