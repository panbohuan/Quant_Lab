# 进阶策略 10：舆情情绪策略（Sentiment Analysis）

> 类型：另类数据 / 情绪分析 ｜ 难度：★★★★★

## 一、核心思路

这是整个进阶篇的「压轴」，因为它代表了一个**数据维度的跃迁**：

- 前面的策略用的都是「**结构化数据**」——价格、PE、ROE，这些是规规矩矩的数字，存好在数据库里；
- 情绪策略第一次用「**非结构化数据**」——股吧帖子、新闻、研报，这些是「文本」，杂乱无章，需要先「理解」再「量化」。

核心逻辑：**市场情绪会影响短期股价**。当一只股票被大量正面新闻、看多帖子包围时，会吸引更多资金涌入，短期推高股价（情绪驱动的定价偏差）。

情绪策略的做法：把「文本」变成「情绪分数」（正面 +1、负面 -1），聚合成每只股票的「情绪因子」，作为选股或择时的依据。

## 二、算法结构

```
每月第1个交易日 → rebalance
  ├─ 获取股票相关的新闻/研报文本
  ├─ 词典法情感分析（正面词-负面词）
  ├─ 聚合得到每只股票的"情绪分"
  └─ 情绪分作为因子选股
```

## 三、函数详解

### 3.1 情感词典法 —— 最简单的文本情感分析

**算法逻辑**：预定义一个「正面词表」和「负面词表」，统计文本里出现多少个正面词、多少个负面词，情绪分 = 正面词数 - 负面词数。

**基本用法**：

```python
pos_words = ['增长', '盈利', '超预期', '突破', '增持', '利好']
neg_words = ['下滑', '亏损', '减持', '违规', '退市', '利空']

def sentiment(text):
    score = 0
    for w in pos_words:
        if w in text:
            score += 1
    for w in neg_words:
        if w in text:
            score -= 1
    return score

print(sentiment('公司利润超预期增长，获大股东增持'))   # +2（超预期、增长、增持）
print(sentiment('公司业绩下滑，遭大股东减持'))         # -2（下滑、减持）
```

**优点**：简单、快、可解释。
**缺点**：不识别否定（「不增长」会被误判为正）、不识别上下文（「利空出尽」其实偏正面）。

### 3.2 情绪代理（本策略的简化实现）

**算法逻辑**：因为聚宽的新闻数据接口需要额外权限，本策略用「量价数据」近似情绪——「涨幅 + 成交额趋势」作为「市场关注度/情绪」的代理。

```python
ret = df['close'].iloc[-1] / df['close'].iloc[0] - 1.0      # 涨幅
money_trend = df['money'].iloc[-1] / df['money'].iloc[0] - 1.0  # 成交额趋势
sentiment = ret + 0.5 * money_trend   # 涨 + 放量 = 情绪暖
```

> 这本质上是「价量情绪代理」，不是真正的文本情绪。真正的情绪分析需要接入新闻/股吧数据，见「改进方向」。

## 四、核心概念详解（面向新手）

### 4.1 什么是「另类数据」（Alternative Data）？

传统量化用的是「老三样」：**价格、成交量、财务报表**。这些数据大家都在用，所以「超额收益」被逐渐磨平。

「另类数据」是**传统金融数据之外的一切信息源**：

- **文本数据**：新闻、研报、股吧帖子、微博、财报电话会纪要；
- **行为数据**：搜索热度、App 下载量、电商销量、卫星图像（数停车场车辆判断商超客流）；
- **供应链数据**：上下游企业的订单、物流数据。

另类数据的价值在于「**别人还没用，你先用了**」，就能获得信息优势。但代价是：数据获取难、清洗难、容易踩合规红线（比如内幕信息）。

### 4.2 为什么「情绪」能辅助决策？

这是行为金融学的核心发现：**投资者不是理性的**。情绪会系统性影响定价：

1. **羊群效应**：看到大家都看好某股票，就跟着买，推高股价（哪怕基本面没变）；
2. **过度反应**：对利好过度乐观、对利空过度悲观，价格短期偏离价值；
3. **注意力驱动**：被大量讨论的股票（高关注度）更容易吸引资金流入。

情绪策略就是**量化这些「非理性」**，在情绪过热时卖出、情绪过冷时买入（反向），或顺势而为（动量）。

### 4.3 情绪策略的坑

1. **情绪是「双刃剑」**：情绪既可能「助推」也可能「反转」，方向判断比想象中难（追高情绪可能接盘）；
2. **文本噪声大**：股吧里大量灌水、水军、广告，真正的「有效情绪」信号被淹没；
3. **中文 NLP 难**：中文文本的情感分析（否定、反讽、网络用语）比英文难得多；
4. **合规风险**：爬取数据可能侵犯隐私、违反平台规则，内幕信息更可能违法。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：本策略用的是「价量情绪代理」，本质是「动量 + 放量」的变体，收益特征接近动量策略。要真正检验「文本情绪」的 alpha，需要接入真实的新闻/股吧数据后重新验证——**切勿把「价量代理」当作「真实情绪」**。

## 六、改进方向

1. **接入真实文本数据**：用聚宽的新闻接口、或第三方数据源（如 Tushare 的新闻数据），做真正的文本情感分析；
2. **升级情感模型**：词典法 → 机器学习分类（朴素贝叶斯、BERT 等预训练模型）；
3. **情绪 + 动量结合**：情绪作为「增强因子」，与动量、估值等传统因子合成；
4. **情绪拐点检测**：不只测「情绪高低」，更测「情绪的边际变化」（从悲观转向乐观是更好的买点）。
