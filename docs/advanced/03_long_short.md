# 进阶策略 3：多空对冲策略（Long-Short Equity）

> 类型：绝对收益 / 市场中性 ｜ 难度：★★★★★

## 一、核心思路

这是整个学习路径里**最关键的一次认知升级**——理解「Alpha 和 Beta 的分离」。

先讲清楚这两个词（面向新手）：

- **Beta（贝塔）**：你「跟随市场」赚的钱。大盘涨 10%，你的股票也涨 10%，这 10% 就是 Beta。它不靠本事，靠「敢在市场里待着」。
- **Alpha（阿尔法）**：你「跑赢市场」赚的钱。大盘涨 10%，你的股票涨 15%，多出的 5% 才是 Alpha——这才是真正的「选股能力」。

普通多头策略赚的是「Alpha + Beta」混合的钱。当大盘暴跌时，你的 Beta 部分会严重拖累收益——**哪怕你选的股票都跑赢了市场，整体还是亏钱**。

多空对冲策略的做法是：

1. **做多**一批你认为最强的股票（赚 Alpha + Beta）；
2. **做空**一批你认为最弱的股票（赚 -Alpha - Beta，反向）；
3. 多空市值相等，**Beta 部分正好抵消**，剩下的就是「强股 Alpha - 弱股 Alpha」——纯粹的 Alpha。

这样，无论大盘涨跌，你赚的是「选股能力的差价」，而不是「赌市场的方向」。这就是「绝对收益」——不依赖牛市也能赚钱。

## 二、算法结构

```
每月第1个交易日 → rebalance
  ├─ 股票池：沪深300成分股（多为可融券标的）
  ├─ 计算动量因子
  ├─ 多头 = 排名前 long_num 只
  ├─ 空头 = 排名后 short_num 只
  ├─ 多头买入正市值，空头卖出负市值
  └─ 保持多头总市值 ≈ 空头总市值（Beta 中性）
```

## 三、函数详解

### 3.1 `order_target_value` 传负数 —— 做空

**算法逻辑**：`order_target_value(security, -500000)` 表示把该股票的持仓调整到「负 50 万元」，即**融券卖出** 50 万元的该股票。这是聚宽实现做空的方式。

**基本用法**：

```python
# 做多：买入 50 万
order_target_value('000001.XSHE', 500000)
# 做空：卖出 50 万（融券）
order_target_value('000001.XSHE', -500000)
# 平仓（无论多空）：目标市值 0
order_target_value('000001.XSHE', 0)
```

**属性与限制**：

| 事项 | 说明 |
|------|------|
| 融券标的 | 不是所有股票都能融券，通常是大盘蓝筹股 |
| 融券成本 | 融券有利息成本，通常高于融资 |
| 涨跌停 | 跌停无法卖出，涨停无法买入（多空都受影响） |

> 重要：聚宽回测中做空的实现是「允许负持仓」，但真实实盘的融券有标的限制、券源限制、利息成本，回测的做空收益**会偏乐观**。

### 3.2 `context.portfolio.positions` —— 持仓字典

**算法逻辑**：返回当前所有持仓的字典，key 是股票代码，value 是 Position 对象（含股数、市值、成本等）。

**基本用法**：

```python
for s in list(context.portfolio.positions):
    pos = context.portfolio.positions[s]
    print(s, pos.total_amount)   # 持仓股数（空头为负）
```

> 多空策略里，空头持仓的 `total_amount` 是负数。所以「清空所有持仓」要遍历 positions 并逐个 `order_target(s, 0)`。

## 四、核心概念详解（面向新手）

### 4.1 什么是「做空」？

做多 = 「先买后卖」，赌它涨。做空 = 「先卖后买」，赌它跌。

做空的流程（以股票为例）：

1. 你判断某股票会跌；
2. 你向券商「借」来这只股票（融券），立刻在市场上卖掉，拿到现金；
3. 等股价真的跌了，你用更便宜的价格「买回来」还给券商；
4. 中间的差价就是你的利润。

比如：借股票时股价 100 元卖出，跌到 80 元买回来还掉，净赚 20 元。

**风险**：如果股票不跌反涨，你买回来的成本更高，亏损没有上限（理论上股价可以无限涨）。

### 4.2 为什么要「多空平衡」（Beta 中性）？

假设你只做多，大盘跌 20%，你的组合大概率也跌（哪怕跌得少点）。但如果你同时做空了等市值的弱势股：

- 大盘跌 20%：多头亏 Beta 部分，但空头赚 Beta 部分；
- 两者 Beta 抵消，剩下的就是「你的多头比空头强多少」。

这就是「市场中性」——组合的涨跌与大盘无关，只取决于你的选股能力。这是对冲基金（如桥水、文艺复兴）最核心的武器之一。

### 4.3 多空对冲的「坑」

1. **空头成本高**：融券利息、券源稀缺，做空在 A 股尤其难（融券标的有限）。
2. **轧空风险**：如果大量人做空同一只票，一旦利好出现，空头争相买回，股价暴涨，亏损惨重。
3. **选股相关性**：如果多头和空头都偏向某一风格（比如都偏小盘），Beta 并没有真正抵消，只是「看起来中性」。
4. **Alpha 不稳定**：动量因子不是永远有效，一旦动量失效，多空两头都亏。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：多空策略的**收益曲线是否平滑**、**最大回撤是否显著小于多头策略**。理想的多空策略收益曲线应该像一条缓坡向上的线，与大盘走势「脱钩」。同时要注意：回测的做空收益偏乐观（真实融券成本更高），实盘预期要打折。

## 六、改进方向

1. **更严格的 Beta 中性**：用回归计算每只股票的 Beta，按 Beta 加权多空，而非简单等市值；
2. **行业中性**：多头和空头在同一行业内配对，剥离行业 Beta；
3. **多因子**：动量只是最简单的一个，可加入估值、质量、波动率等多因子；
4. **动态调整**：根据市场波动率动态调整多空总敞口。
