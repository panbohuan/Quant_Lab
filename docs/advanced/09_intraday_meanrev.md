# 进阶策略 9：高频均值回归策略（Intraday Mean Reversion）

> 类型：日内交易 / 均值回归 ｜ 难度：★★★★★

## 一、核心思路

前面所有策略都是「**日频**」（每天或每月看一次），本策略第一次进入「**日内**」——用分钟级数据，捕捉一天之内的交易机会。

核心逻辑是「**超跌反弹**」（均值回归）：

- 某只股票开盘后 30 分钟内突然暴跌 2% 以上，往往是因为「情绪化抛售」或「某个大单砸盘」；
- 这种短期的「过度下跌」偏离了股票的「合理价值」，之后倾向于「回归」——即反弹；
- 策略在超跌时买入，博取日内反弹。

为什么会有这种「过度反应」？行为金融学解释：投资者对突发的负面信息**反应过度**（over-reaction），价格在短时间内跌过头，随后理性资金进场，把价格拉回「合理水平」。

## 二、算法结构

```
每分钟运行（run_daily every_bar）→ minute_trade
  ├─ 只在开盘 9:30~10:00 执行（超跌最有意义）
  ├─ 遍历股票池
  ├─ 算"开盘至今"累计跌幅
  ├─ 跌幅超阈值 且 未跌停 → 买入博反弹
  └─ 控制持仓上限
收盘后（after_trading_end）→ 清空当日买入记录
```

## 三、函数详解

### 3.1 `run_daily(func, time='every_bar')` —— 分钟级运行

**算法逻辑**：`run_daily` 的 `time` 参数除了传具体时间（如 `'09:30'`），还能传 `'every_bar'`，表示「每个 bar（分钟）都运行」。这是日内策略的调度方式。

**基本用法**：

```python
run_daily(minute_trade, time='every_bar')   # 每分钟运行
run_daily(market_open, time='09:30')        # 每天9:30运行一次
run_daily(market_close, time='14:50')       # 每天14:50运行一次
```

> 注意：分钟级回测会**显著变慢**（每分钟都要跑一遍函数），且需要的数据量、计算量是日频的几十倍。

### 3.2 `context.current_dt.time()` —— 当前时间（判断日内时段）

**算法逻辑**：`context.current_dt` 是当前回测时间（datetime 对象），`.time()` 取出时间部分，用来判断「现在是不是开盘后 30 分钟内」。

**基本用法**：

```python
current_time = context.current_dt.time()
if current_time.hour == 9 and current_time.minute < 30:
    # 开盘后30分钟内
    pass
```

### 3.3 `get_current_data()[s].day_open` —— 当日开盘价

**算法逻辑**：`day_open` 是当天开盘价，配合 `last_price`（当前价）就能算出「开盘以来的涨跌幅」。

```python
open_price = d.day_open      # 开盘价
last_price = d.last_price    # 当前价（分钟级回测中为最新成交价）
change = last_price / open_price - 1.0   # 开盘以来涨幅
```

### 3.4 `after_trading_end` —— 收盘后钩子

**算法逻辑**：聚宽会在每天收盘后自动调用这个函数（如果定义了）。用于「每日重置状态」，比如清空当天的买入记录。

```python
def after_trading_end(context):
    g.bought_today = set()   # 次日重新开始
```

## 四、核心概念详解（面向新手）

### 4.1 什么是「均值回归」？

均值回归是金融里最经典的规律之一：**价格涨多了会跌回来，跌多了会涨回去**，长期围绕某个「均值」波动。

就像弹簧：拉得太长（涨太多）会回弹（跌），压得太紧（跌太多）会回弹（涨）。

它与「动量」正好相反：

- **动量**：涨的继续涨（强者恒强）；
- **均值回归**：涨的会跌回来（物极必反）。

两者看似矛盾，其实适用于**不同时间尺度**：

- **短期（日内~1周）**：均值回归更明显（情绪性超买超卖会修复）；
- **中期（1~12个月）**：动量更明显（趋势一旦形成会延续）。

### 4.2 为什么日内交易成本是「命门」？

这是高频策略最容易被新手忽视、却最致命的一点。

日频策略一个月交易一两次，手续费可以忽略。但日内策略**每天交易好几次**，交易成本被放大了几十倍：

- **手续费**：每次买卖都有佣金（万三左右）；
- **滑点**：你想以 10.00 元买，实际可能 10.02 元才成交（市场冲击）；
- **T+1 约束**：A 股「当天买入、次日才能卖」，所以「日内买入博反弹」实际是「今天买、明天卖」，要承担隔夜风险。

**一个残酷的现实**：很多日内均值回归策略在「不计成本」的回测里收益不错，但一旦加上真实的交易成本，收益立刻归零甚至为负。**日内策略的核心不是「预测准」，而是「成本控制」**。

### 4.3 日内均值回归的坑

1. **隔夜风险**：因为 T+1，今天买的股票明天才能卖，晚上可能出利空跳空低开；
2. **超跌≠反弹**：有些暴跌是「基本面真的坏了」（比如暴雷），会持续下跌不反弹——这就是「接飞刀」；
3. **流动性陷阱**：暴跌时可能想买买不进（跌停），想卖卖不出；
4. **统计显著性**：日内波动噪声极大，策略收益可能只是「运气」，需要大量样本验证。

## 五、回测说明

- **回测区间**：建议缩短到 1~2 年（分钟级回测极慢，10 年要跑很久）
- **初始资金**：100 万元
- **频率**：分钟级

**重点观察**：一定要对比「扣费前 vs 扣费后」的收益！如果扣费后收益大幅缩水甚至转负，说明这个策略在成本上不成立。同时关注换手率——日内策略换手率极高，是收益的天敌。

## 六、改进方向

1. **更精细的成本模型**：用真实的买卖价差、冲击成本，而非固定滑点；
2. **过滤基本面暴雷**：超跌前先看是不是有利空消息（排除「接飞刀」）；
3. **结合成交量**：超跌 + 放量 = 更可能是情绪化抛售（反弹概率高）；
4. **T+0 品种**：改用可转债、ETF（部分可 T+0）规避 T+1 约束。
