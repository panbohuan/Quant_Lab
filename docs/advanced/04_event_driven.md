# 进阶策略 4：事件驱动策略（Event-Driven）

> 类型：另类策略 / 事件驱动 ｜ 难度：★★★★☆

## 一、核心思路

前面所有策略用的是「**连续因子**」——价格、PE、ROE 这些每天都在变、可以连续取值的数字。事件驱动策略切换到「**离散事件**」——财报发布、分红送转、股东增持、指数调仓，这些是「在某一天突然发生」的事情。

背后的核心假设是：**市场对事件信息的反应是滞后的、不充分的**。

举个例子：一家公司发布财报，利润暴增 50%。理论上股价应该立刻涨到位，但现实中：

- 很多投资者没来得及第一时间看到；
- 看到的人里，有人怀疑、有人观望；
- 等更多人慢慢消化这个利好，股价才会逐步「涨到位」。

事件驱动策略就是**抢在「股价完全反映事件」之前买入**，赚取这段「反应滞后」的钱。

## 二、算法结构（以「财报发布」事件为例）

```
每日运行 → trade
  ├─ 卖出持有超过 hold_days 的股票
  ├─ 发现"未来10天内将发财报"的事件股票
  ├─ 过滤 ST/停牌等
  ├─ 买入新事件股票（控制持仓上限）
  └─ 记录买入日期，到期卖出
```

## 三、函数详解

### 3.1 `income` 表与 `report_date` —— 财报日期

**算法逻辑**：`income` 是利润表，`report_date` 字段记录财报的披露日期。通过查询它，可以知道「哪些股票即将发财报」。

**基本用法**：

```python
q = query(
    income.code,
    income.report_date
).filter(
    income.code.in_(pool)
)
df = get_fundamentals(q, date='2024-01-01')
df = df.set_index('code')
print(df['report_date'])   # 每只股票的财报披露日期
```

### 3.2 `datetime.strptime` —— 字符串转日期（防未来函数的关键）

**算法逻辑**：财务数据里的日期有时是字符串（`'2024-03-15'`），需要转成 `date` 对象才能做日期运算。

**基本用法**：

```python
from datetime import datetime
report_date = datetime.strptime('2024-03-15', '%Y-%m-%d').date()
days_until = (report_date - today).days   # 距离今天还有几天
```

> **防未来函数的要点**：必须用「公告日」而非「事件实际发生日」。比如财报是 3 月 15 日披露的，你不能在 3 月 14 日就「知道」财报内容。正确做法是：3 月 15 日公告后才买入。本策略用「未来 10 天将发财报」作为买入信号，是在「事件发生前」买入博预期，这是另一种事件策略（预期驱动），但同样要注意：**不能用到公告日后才有的信息**。

### 3.3 `g.buy_date` 字典 —— 记录买入日期

**算法逻辑**：用一个全局字典 `g.buy_date[stock] = 买入日期`，实现「买入后持有 N 天再卖」的逻辑。这是聚宽策略里常见的「状态记录」技巧。

**基本用法**：

```python
g.buy_date = {}
# 买入时记录
g.buy_date[s] = context.current_dt.date()
# 检查是否到期
if (today - g.buy_date[s]).days >= g.hold_days:
    order_target(s, 0)   # 卖出
    del g.buy_date[s]
```

## 四、核心概念详解（面向新手）

### 4.1 常见的「事件」类型

| 事件类型 | 含义 | 典型交易逻辑 |
|----------|------|-------------|
| 财报发布 | 公司披露季报/年报 | 预期超预期→买入 |
| 分红送转 | 派息、送股、转增 | 高送转→短期炒作 |
| 股东增持 | 大股东买入自家股票 | 看好信号→跟随 |
| 指数调仓 | 股票调入/调出指数 | 调入→被动资金买入 |
| 并购重组 | 公司被收购/重组 | 停牌前埋伏 |
| 业绩预告 | 提前披露业绩区间 | 预增→买入 |

### 4.2 为什么事件能产生「定价偏差」？

核心是**信息不对称 + 行为偏差**：

1. **信息不对称**：大机构、内幕人士比散户更早知道信息，股价不会瞬间反映；
2. **反应不足**：投资者对利好利空的反应是渐进的（行为金融学的「锚定效应」「保守偏差」）；
3. **流动性限制**：大资金无法一次性买入，只能分批建仓，导致股价缓慢上涨。

事件驱动就是利用这些「市场不完美」，在事件信息传播的过程中获利。

### 4.3 事件驱动最大的坑：未来函数

这是事件驱动策略最致命的陷阱。举一个反例：

> 错误做法：用「财报披露后」的数据（比如利润暴增）作为「披露前」的买入信号。

这等于「开了上帝视角」，回测收益高得离谱，实盘必然失效。**正确的做法**是严格区分「事件公告日」和「数据可得日」，只用公告日当天及之前能拿到的信息做决策。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：事件驱动策略的收益往往「脉冲式」——大部分时间平淡，事件集中时突然跳升。要关注：事件频率是否足够（太少则样本不足、结果不可靠）、以及「事件后持有几天最优」（持有期参数很敏感）。

## 六、改进方向

1. **多事件组合**：不只财报，叠加股东增持、指数调仓等多个事件源；
2. **事件质量筛选**：区分「超预期」和「符合预期」，只交易超预期事件；
3. **精细化窗口**：研究事件前后各几天收益最优，而非固定持有期；
4. **情绪叠加**：事件 + 舆情情绪（如进阶策略10）结合，判断市场对事件的反应强度。
