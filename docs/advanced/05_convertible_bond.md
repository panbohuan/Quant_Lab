# 进阶策略 5：可转债双低策略（Convertible Bond）

> 类型：跨品种 / 可转债 ｜ 难度：★★★★☆

## 一、核心思路

这是从「股票」拓展到「可转债」的第一课。先理解可转债是什么。

**可转债 = 债券 + 看涨期权**。它是一张「公司欠你的借条」，但附带一个权利：在未来某个时点，你可以按约定的「转股价」把它换成公司的股票。

所以可转债有「双重性格」：

- **债性**：如果股价一直不涨，你至少能拿回本金 + 利息（下有保底）；
- **股性**：如果股价大涨，你可以转成股票，跟着一起赚（上不封顶）。

这正是它最吸引人的地方：**跌的时候像债券（抗跌），涨的时候像股票（能涨）**。

「双低策略」就是在所有可转债里，挑出「**价格低 + 转股溢价率低**」的品种：

- **价格低**：接近债底，下跌空间小（保底）；
- **转股溢价率低**：转债价格和它对应的股票价值（转股价值）差距小，股性足（弹性好）。

## 二、算法结构

```
每月第1个交易日 → rebalance
  ├─ get_all_securities(types=['cb']) 获取全部可转债
  ├─ 过滤停牌/无行情
  ├─ 计算"双低值" = 价格 + 转股溢价率×100
  ├─ 按双低值升序取前 N 只
  └─ 等权买入
```

## 三、函数详解

### 3.1 `get_all_securities(types=['cb'])` —— 获取可转债列表

**算法逻辑**：与获取股票（`types=['stock']`）类似，传 `'cb'`（convertible bond）返回全部可转债。

**基本用法**：

```python
cb_list = get_all_securities(types=['cb'], date='2024-01-01').index.tolist()
print(cb_list)   # 可转债代码列表，如 ['113001.XSHG', '123001.XSHE', ...]
```

**types 的常见取值**：

| types 值 | 含义 |
|----------|------|
| `['stock']` | 股票 |
| `['fund']` | 基金（含 ETF） |
| `['etf']` | ETF |
| `['cb']` | 可转债 |
| `['index']` | 指数 |

### 3.2 `get_current_data()[cb].last_price` —— 转债现价

**算法逻辑**：获取可转债的当前价格（`last_price`）、是否停牌（`paused`）等信息，与股票用法一致。

## 四、核心概念详解（面向新手）

### 4.1 什么是「转股溢价率」？

这是可转债最核心的指标，必须彻底搞懂。先铺垫两个概念：

- **转股价值** = 当前能换成多少股票价值。公式：`转股价值 = (100 / 转股价) × 正股价`。意思是「这张面值 100 元的转债，现在换成股票值多少钱」。
- **转股溢价率** = `(转债价格 / 转股价值) - 1`。意思是「你买转债比直接买股票贵了多少」。

**打个比方**：一张转债面值 100 元，转股价 10 元，那么它能换 10 股。如果正股价现在 12 元，转股价值 = 10 × 12 = 120 元。如果转债市场价是 130 元，那么转股溢价率 = 130/120 - 1 = 8.3%。

**溢价率越低越好**（对双低策略而言），因为：
- 溢价率低 → 转债价格紧跟正股，股性强，正股涨它也涨（弹性好）；
- 溢价率高 → 转债已经「透支」了正股的涨幅，正股涨它不涨（钝化）。

### 4.2 什么是「债底保护」？

可转债本质是债券，有「到期赎回价」——公司承诺到期按某个价格（通常 106~110 元）赎回。加上持有期间的利息，就构成了「债底」。

**意思是**：即使正股跌成渣，只要你持有到期，公司还得按赎回价还你钱。所以转债价格跌到接近债底时，就「跌不动了」——这就是「下有保底」。

**双低策略的精髓**：买「价格接近债底（保底）+ 溢价率低（弹性好）」的转债，实现「跌有限、涨无限」的赔率优势。

### 4.3 双低策略的坑

1. **违约风险**：债底保护的前提是「公司还得起钱」。如果公司破产违约，债底也保不住（近年有可转债违约案例）。
2. **强赎风险**：股价大涨触发「强制赎回」条款时，公司会以略高于面值的价格强制赎回，转债的上涨空间被封顶——所以转债并非真的「上不封顶」，涨太多会被强赎。
3. **流动性差**：很多转债成交清淡，买卖价差大，回测的成交价格可能偏乐观。
4. **双低陷阱**：「价格低 + 溢价率低」的转债，往往是正股基本面差、市场不看好，可能「低价有低价的道理」。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：可转债双低策略的最大优势是**回撤小、胜率高**（因为债底保护）。重点看最大回撤是否显著低于股票策略，以及在不同市场环境下（牛市/熊市）的表现差异——牛市时股性强能涨，熊市时债性保护抗跌。

## 六、改进方向

1. **三低策略**：价格低 + 溢价率低 + 剩余规模小（小盘转债弹性更大）；
2. **加入正股质地**：筛选正股基本面好、有题材的转债；
3. **下修博弈**：买入可能触发「转股价下修」的转债（下修利好转债）；
4. **轮动频率优化**：双低值变化快，可考虑双周或每周轮动。
