# 进阶策略 8：机器学习因子合成（ML Factor Combination）

> 类型：机器学习进阶 / 因子合成 ｜ 难度：★★★★★

## 一、核心思路

入门篇的策略 10（机器学习选股）已经引入了随机森林，本策略是它的「升级版」——重点不在「用 ML 选股」，而在「**用 ML 合成因子**」。

回顾一下因子合成的进化史：

1. **入门篇策略 7**：手工设定权重，线性加权（`0.4×动量 + 0.3×估值 + 0.3×质量`）；
2. **进阶篇策略 7（因子择时）**：根据环境动态调整权重（还是线性加权）；
3. **本策略（ML 因子合成）**：让模型**自己学习**「这些因子该怎么组合」，而且能捕捉**非线性关系**。

关键区别在「**非线性**」：手工加权永远是「因子 A 加因子 B」，是线性的。但现实中，因子的作用可能是「非线性」的——比如「低 PE + 高 ROE」的组合效果，可能远大于两者单独效果的简单相加（1+1 > 2）。树模型（随机森林、XGBoost）天然能捕捉这种「因子之间的交互作用」。

## 二、算法结构

```
每月第1个交易日 → rebalance
  ├─ 构造特征矩阵（动量/波动率/PE/ROE）
  ├─ 用历史数据训练随机森林（X → 未来收益）
  ├─ 用模型预测当期股票的"预期收益"
  └─ 按预测分排序取前 N 只
```

## 三、函数详解

### 3.1 `RandomForestRegressor` —— 随机森林回归

**算法逻辑**：随机森林 = 很多棵「决策树」的集成。每棵树基于一部分特征、一部分样本独立训练，最后「投票/平均」得到结果。用「集成」降低单棵树的过拟合。

**基本用法**：

```python
from sklearn.ensemble import RandomForestRegressor
model = RandomForestRegressor(
    n_estimators=100,   # 树的棵数（越多越稳，但越慢）
    max_depth=5,        # 每棵树的最大深度（限制深度防止过拟合）
    random_state=42     # 随机种子（保证结果可复现）
)
model.fit(X_train, y_train)      # 训练
y_pred = model.predict(X_test)   # 预测
```

**核心参数**：

| 参数 | 含义 | 调参建议 |
|------|------|----------|
| `n_estimators` | 树的数量 | 100~500，越大越稳越慢 |
| `max_depth` | 树的最大深度 | 3~10，越小越防过拟合 |
| `min_samples_leaf` | 叶节点最小样本数 | 越大越防过拟合 |
| `max_features` | 每棵树用多少特征 | 默认 sqrt，减少可防过拟合 |

### 3.2 `model.fit` / `model.predict` —— 训练与预测

**算法逻辑**：`fit(X, y)` 用特征 X 和标签 y 训练模型，`predict(X)` 用训练好的模型对新数据 X 打分。这是 sklearn 所有模型的统一接口。

**基本用法**：

```python
# X 是特征矩阵（DataFrame），y 是标签（未来收益）
model.fit(X_train, y_train)
predicted_return = model.predict(X_current)   # 预测当期预期收益
```

### 3.3 特征矩阵的构造（`compute_features`）

**算法逻辑**：把多个因子拼成一张「特征表」，每行一只股票，每列一个因子。这是 ML 的「输入格式」。

```python
X = pd.DataFrame(index=股票列表)
X['momentum'] = ...     # 动量因子
X['volatility'] = ...   # 波动率因子
X['pe_ratio'] = ...     # 估值因子
X['roe'] = ...          # 质量因子
```

## 四、核心概念详解（面向新手）

### 4.1 什么是「特征」和「标签」？

这是机器学习最基础的两个词，用「教小孩认动物」来比喻：

- **特征（Feature）**：你给模型的「线索」。比如「四条腿」「有毛」「会汪汪叫」——对应量化里的「动量」「PE」「ROE」这些因子；
- **标签（Label）**：你要模型预测的「答案」。比如「这是狗」——对应量化里的「未来 5 天涨了 3%」。

监督学习的本质：给模型看「很多组（特征 → 标签）的配对」，让它自己总结规律，以后见到新的特征就能猜标签。

### 4.2 量化 ML 的「标签」怎么设计？

这是量化 ML 和普通 ML 最大的区别之一。

**错误做法**：标签 = 「未来 5 天涨了没有」（0/1）。问题：这个标签受大盘影响太大，牛市里几乎全涨，模型学到的是「市场方向」而非「选股能力」。

**正确做法**：标签 = 「未来 5 天这只股票的收益，在全市场的**排名**」。比如未来 5 天收益排进前 30% 的标为「正样本」。这样模型学的是「相对强弱」，剥离了大盘的干扰。

### 4.3 为什么要「时序交叉验证」？

普通 ML 用「随机 K 折」交叉验证：把数据随机分成 K 份，轮流用 K-1 份训练、1 份测试。但在金融数据里这样做会「**泄露未来**」：

- 假设你用 2023 年的数据训练，2020 年的数据测试——这等于「用未来预测过去」，测试结果虚高。

**正确做法是「时序交叉验证」（Walk-Forward）**：永远只用「过去」训练、「未来」测试。比如用 2016-2020 训练、2021 测试；再用 2016-2021 训练、2022 测试……这样模拟真实交易场景。

### 4.4 为什么 ML 因子合成「可解释性」重要？

随机森林、神经网络都是「黑箱」——它们能给出结果，但很难解释「为什么」。这在量化里是危险的：

- 如果模型不可解释，你无法判断它是「学到了真规律」还是「记住了噪声」；
- 一旦市场环境变化，黑箱模型可能突然失效，你也不知道为什么。

**树模型的优势**：可以通过「特征重要性」（feature importance）看到每个因子贡献了多少。所以入门用随机森林比神经网络更合适——至少能解释。

## 五、回测说明

- **回测区间**：2016-01-01 ~ 2026-01-01
- **初始资金**：100 万元
- **基准**：沪深300

**重点观察**：ML 因子合成 vs 手工加权（入门策略7、进阶策略7），看 ML 能否捕捉到「手工加权遗漏的非线性关系」。同时务必观察**样本外表现**——如果训练集收益高、测试集差，就是过拟合了。

> **诚实提示**：本策略代码里的「标签」用了占位（`np.random.rand`），因为真正的历史滚动训练需要大量历史数据和时间，在聚宽回测里跑会非常慢。完整实现需要：① 提前准备历史特征和标签；② 用 Walk-Forward 逐期训练；③ 严格样本外测试。这是从「教学」到「实盘」之间最关键的差距，请务必理解这一点。

## 六、改进方向

1. **升级模型**：随机森林 → XGBoost / LightGBM（更快、更准，是业界标准）；
2. **真正的 Walk-Forward**：滚动训练、滚动预测，严格样本外验证；
3. **特征重要性分析**：定期查看哪些因子贡献大，剔除失效因子；
4. **集成学习**：多个模型（RF + XGBoost + 神经网络）投票，降低单一模型风险。
