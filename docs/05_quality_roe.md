# 策略 5：单因子质量选股（ROE 质量因子）

> 策略类型：单因子选股（基本面·质量） ｜ 难度：★★★☆☆ ｜ 前置知识：策略3（财务数据查询）

## 一、核心思路：质量投资与 ROE

如果说策略3是买"便宜的"、策略4是买"小的"，那策略5买的是"**好的**"——盈利能力强的优质公司。

### 1.1 净资产收益率 ROE（Return on Equity）

$$ROE = \frac{\text{净利润}}{\text{净资产（股东权益）}}$$

**含义**：股东每投入 1 元净资产，公司一年能赚多少钱。ROE=15% 意味着每 100 元股东资本创造 15 元利润。

**为什么 ROE 能辅助决策？**
- ROE 是衡量公司**赚钱效率**最综合的指标，巴菲特最看重它："如果只能看一个指标，我看 ROE"；
- 长期高 ROE 往往意味着公司拥有**护城河**（品牌、技术、成本、网络效应等），能持续创造超额利润；
- 高 ROE 公司质量更好，抗风险能力更强，在熊市更抗跌（"质量溢价"）。

### 1.2 杜邦分析：ROE 的三个来源（理解 ROE 的关键）

杜邦公式把 ROE 拆成三部分，帮助我们理解高 ROE 的"成色"：

$$ROE = \underbrace{\frac{净利润}{营收}}_{净利率} \times \underbrace{\frac{营收}{总资产}}_{资产周转率} \times \underbrace{\frac{总资产}{净资产}}_{权益乘数(杠杆)}$$

- **高净利率**：茅台式——卖得贵、赚得多（盈利质量高，最优）；
- **高周转**：沃尔玛式——薄利多销、快速周转（经营效率高，次优）；
- **高杠杆**：银行式——靠借钱放大收益（风险高，ROE 虚高，需警惕）。

> 所以同样是 ROE=20%，靠高杠杆堆出来的"含金量"远不如靠高净利率的。这就是为什么进阶策略会**同时看 ROE 与资产负债率**。

### 1.3 其他质量指标

| 指标 | 含义 | 方向 |
|------|------|------|
| `indicator.roa` | 总资产收益率 = 净利润/总资产 | 越高越好（不含杠杆因素，比ROE更"纯"） |
| `indicator.gross_profit_margin` | 毛利率 = (营收-成本)/营收 | 越高越好（反映定价权与竞争壁垒） |
| `indicator.inc_net_profit_year_on_year` | 净利润同比增长率 | 越高越好（成长性） |

## 二、算法结构

与策略3/4一致，因子换成 `indicator.roe`，排序方向为**降序**（越大越好）：

```
每月第1个交易日 → rebalance
  ├─ 股票池：全市场
  ├─ 过滤 ST / 停牌
  ├─ 查询 indicator.roe / roa / gross_profit_margin
  ├─ 清洗 dropna
  ├─ 按 ROE 降序取前 30 只
  └─ 换仓等权
```

## 三、函数详解

### 3.1 `indicator` 表与季度数据

`indicator` 是**财务指标表**，数据来自财报，**按季度披露**（季报/中报/年报）。因此：

- 用 `date` 参数时，`get_fundamentals` 返回**截至该日已披露的最新一期**财务指标；
- 也可以用 `statDate` 指定某个报告期。

```python
q = query(indicator.roe, indicator.roa).filter(valuation.code.in_(pool))
df = get_fundamentals(q, date=context.current_dt.date())       # 最新已披露
df = get_fundamentals(q, statDate='2024q4')                    # 2024年报
```

### 3.2 `desc()` 与 `asc()` 排序

`query(...).order_by(字段.desc())` 降序（大→小），`.asc()` 升序（小→大）。ROE 越大越好，所以用 `desc()`。

```python
.order_by(indicator.roe.desc())    # 高ROE排前面
.order_by(valuation.pe_ratio.asc())# 低PE排前面（策略3）
```

### 3.3 质量因子的清洗要点

与估值因子不同，质量因子**一般不做正负过滤**（ROE 为负只是代表亏损，排序时会自然排到后面）。但要注意：

```python
df = df.dropna(subset=['roe'])   # 剔除 ROE 缺失（如刚上市无财报）
```

进阶做法是**剔除极端值**（如 ROE > 100% 或 < -50% 的异常值），因为它们往往是财务操纵或一次性损益造成的假象，会污染排名。

## 四、回测说明

**回测参数（建议）：** 区间 2016-01-01 ～ 2026-01-01，初始资金 100 万，月度调仓，基准沪深300。

**关注指标：** 年化收益、最大回撤、夏普，以及**质量因子在牛熊中的表现差异**（熊市抗跌、牛市可能跑输高弹性成长股）。

**如实说明：** 需在聚宽平台运行获取真实数据。风险提示：
- 高 ROE 公司往往已被市场充分定价（估值不便宜），**质量因子单独使用的超额收益可能有限**；
- **财务数据滞后**：用 `date` 取的是"已披露"数据，不会偷看未来，但要意识到财报反映的是过去几个月的经营；
- 高 ROE 需辨别"可持续性"：一次性收益、高杠杆都会造成 ROE 虚高。

## 五、改进方向

1. **质量 + 估值结合**："便宜的好公司"（高 ROE 且低 PE/PB），这是价值投资精髓（见策略7多因子）；
2. 用**连续多年 ROE**（如近3年 ROE 均 > 15%）而非单期，筛选出真正稳定的优质公司；
3. 剔除高杠杆的"伪高质量"：ROE 高但 `asset_liability_ratio` 也高的股票要降权。
