# Quant_Lab —— 面向量化初学者的入门指导库

> 一个系统、完整的量化投资学习仓库。帮助你从零入门量化策略，掌握**聚宽（JoinQuant）原生框架**与 **backtrader 本地回测框架**两套写法，并逐步延伸到机器学习、AI 大模型、区块链等前沿技术。**盈利不是目的，目的是框架本身的学习和熟悉。**

> **v4.0.0 更新（2026-10）**：策略目录拆成**两套并行框架**——`strategies/joinquant/`（20 个聚宽原生策略，粘贴到官网即可回测）与 `strategies/backtrader/`（20 个 backtrader 本地策略，**无需任何账号、无需聚宽额度**）。同时接入**免费长历史数据源**，把回测区间从"几天"拉长到 **10 年以上**。详见 [CHANGELOG.md](CHANGELOG.md)。

## 一、这是什么

本仓库的目标不是"给出能赚钱的策略"，而是帮助你**系统地掌握量化的两套主流工作方式**：

- **云端路线**：在聚宽平台上写策略、用平台数据和引擎回测（入门最快，数据最全）；
- **本地路线**：在自己的电脑上用 backtrader 回测（完全可控、免费、可离线、能接自己的数据）。

**三大学习支柱**：

1. **策略实战**：**40 个策略文件**（20 个聚宽原生 + 20 个 backtrader 本地），两两对应，从双均线技术择时到机器学习因子合成；
2. **基础功底**：pandas、聚宽 `get_` 系列函数、backtrader API 等量化必备工具的系统讲解；
3. **前沿延伸**：机器学习、AI 大模型（LLM/Agent/RAG）、区块链三大板块的入门到进阶。

```
【入门路径】技术择时 → 单因子选股 → 因子合成 → 因子提纯/加权 → 机器学习选股
【进阶路径】风险控制 → 中观配置 → 绝对收益 → 另类策略 → 跨品种 → 资产配置 → ML进阶
【知识路径】pandas → 聚宽函数 → 机器学习 → AI大模型 → 区块链
```

## 二、两套策略体系（同一策略，两种写法）

| | **A 组：聚宽原生** | **B 组：backtrader 本地** |
|---|---|---|
| 目录 | `strategies/joinquant/` | `strategies/backtrader/` |
| 文件命名 | `s01`…`s10`、`a01`…`a10` | `bt_s01`…`bt_s10`、`bt_a01`…`bt_a10` |
| 怎么运行 | 登录聚宽 → 新建策略 → **整段粘贴** → 编译运行 | 本机终端：`python strategies/backtrader/beginner/bt_s01_ma_cross.py` |
| 需要账号 | 需要免费注册聚宽 | **不需要任何账号** |
| 需要装依赖 | **不需要** | `pip install -r requirements.txt` |
| 数据 | 聚宽平台内置 | 免费公开数据源（新浪/中证/东财/申万/乐咕乐股） |
| 回测内核 | 聚宽平台引擎 | **backtrader 官方引擎** |

> **关键承诺**：B 组的回测内核 **100% 是 backtrader 官方开源框架**，本仓库**没有自研回测引擎**。
> `btlab/` 只做"数据适配 + 样板代码封装"（拉数据、算绩效、画图、A 股手续费模型），
> 撮合、持仓、账务、盈亏、净值全部由 backtrader 的 `Cerebro` / `Broker` 完成。
>
> A 组是**纯聚宽原生代码**：零 `import`、零本地入口、零配置，修改 B 组不会影响 A 组。

## 八、快速开始

### A 组：聚宽策略（最快，零安装）

1. 注册 [聚宽 JoinQuant](https://www.joinquant.com)（免费）；
2. 「我的策略」→「新建策略」；
3. 把 `strategies/joinquant/beginner/s01_ma_cross.py` 的内容**整段粘贴**进去（覆盖模板代码）；
4. 点「编译运行」。回测区间/初始资金在右上角「回测面板」里设。

> 这些文件是纯聚宽原生代码：不需要装任何东西、不需要配置账号密码。

### B 组：backtrader 本地回测

```bash
# 1. 建虚拟环境
python -m venv .venv
.venv\Scripts\activate                 # Windows
# source .venv/bin/activate            # macOS / Linux

# 2. 装依赖（核心只有 6 个包）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 跑一个单标的策略（首次会联网拉数据，约几秒到几分钟）
python strategies/backtrader/beginner/bt_s01_ma_cross.py
```

输出：绩效报告打印到终端，净值图保存到 `results/bt_s01_result.png`。
完整指南（数据来源、缓存机制、工具层说明、与聚宽差异对照、FAQ）见
[`docs/本地回测使用指南.md`](docs/本地回测使用指南.md)。

### 调参

**B 组**：每个文件顶部有参数区，直接改：

```python
START = '2018-01-01'        # 回测起点
```

## 十一、风险提示与免责声明

- 本仓库所有策略**仅供学习量化框架与编程方法**，**不构成任何投资建议**；
- 历史回测收益**不代表未来表现**，策略普遍存在**过拟合、幸存者偏差、未来函数**等风险；
- **B 组本地回测存在明确的数据口径近似**（详见第 6 节警告与使用指南第 5 节），
  其绩效数字**不能与聚宽版直接对比**；
- 小市值、动量、低估值等因子策略在特定时期可能产生**大幅回撤**，请勿直接实盘；
- 多空对冲、日内交易、事件驱动等进阶策略在真实市场面临**融券限制、交易成本、流动性**等回测无法完全模拟的约束；
- 实盘交易还需考虑：流动性、冲击成本、涨跌停限制、停复牌、财务数据披露滞后等因素。
