# JoinQuant_Strategies —— 聚宽(JoinQuant)量化策略学习库

> 面向量化初学者的策略代码库：**10 个从简单到复杂的完整聚宽策略**，覆盖主流因子选股策略，每个策略都附带**完整可运行代码 + 逐行思路详解 + 函数解析 + 基本面概念**。

> **v2.0 更新（2026-09）**：修复了导致策略无法正常交易的几个关键问题，并大幅加深了函数解析与概念讲解。详见文末「更新日志」。

---

## 一、这是什么

本仓库的目标不是"给出能赚钱的策略"，而是帮助初学者**熟悉聚宽(JoinQuant)框架**：从最基础的技术择时，逐步进阶到单因子选股 → 多因子合成 → 因子中性化 → 因子 IC 加权 → 机器学习选股。通过 10 个递进式策略，掌握聚宽常见函数、策略基本写法和进阶写法。

**学习路径**：

```
技术择时(1) → 单因子选股(2~5) → 因子合成(6~7) → 因子提纯/加权(8~9) → 机器学习(10)
   入门          基础              进阶               高级              延伸
```

## 四、环境准备

1. 注册 [聚宽 JoinQuant](https://www.joinquant.com) 账号（免费）；
2. 进入「策略研究 / 我的策略」→「新建策略」；
3. 把 `strategies/` 里的 `.py` 代码**整体复制粘贴**到代码编辑区；
4. 设置回测参数（见下），点击「编译运行」。

## 五、回测参数建议

每个策略文档的「回测说明」都给出了建议参数，通用配置如下：

- **回测区间**：2016-01-01 ～ 2026-01-01（约 10 年）
- **初始资金**：100 万元
- **基准**：沪深300（000300.XSHG）
- **频率**：日频
- **手续费/滑点**：已在代码中通过 `set_order_cost` / `set_slippage` 设定

> **关于回测数据（重要、如实说明）**：本仓库的每个策略都需要在聚宽**云端**运行才能得到真实回测数字，因此文档中**不预置回测收益率/最大回撤等数字**（避免给出无法复现或误导的数值）。请自行运行后在结果页查看：年化收益、最大回撤、夏普比率、胜率、换手率等指标。

## 六、聚宽常用函数速查

| 函数 | 用途 |
|------|------|
| `initialize(context)` | 初始化，注册配置与定时任务 |
| `run_daily/run_weekly/run_monthly` | 每日/每周/每月定时运行 |
| `set_benchmark / set_option` | 设定基准 / 真实价格模式 |
| `set_order_cost / set_slippage` | 设定手续费 / 滑点 |
| `get_index_stocks / get_all_securities` | 获取指数成分股 / 全市场标的 |
| `get_current_data()` | 当日实时数据（is_st / paused 等） |
| `attribute_history / history` | 取历史行情（单标的 / 批量） |
| `query(...) / get_fundamentals(...)` | 查询基本面财务数据 |
| `valuation / indicator / balance / income` | 财务数据表（估值/指标/资产负债/利润） |
| `get_industry(...)` | 查询股票所属行业 |
| `order / order_value / order_target_value` | 下单（股数 / 金额 / 目标市值） |
| `log.info(...)` | 输出日志 |

> 更完整的 `get_` 系列数据获取函数（含核心参数、返回值、基本用法、简单例子、全部属性）见 [`docs/common_functions.md`](docs/common_functions.md)。

## 七、风险提示与免责声明

- 本仓库所有策略**仅供学习聚宽框架与量化编程方法**，**不构成任何投资建议**；
- 历史回测收益**不代表未来表现**，策略普遍存在**过拟合、幸存者偏差、未来函数**等风险；
- 其中小市值、动量、低估值等因子策略在特定时期可能产生**大幅回撤**，请勿直接实盘；
- 实盘交易还需考虑：流动性、冲击成本、涨跌停限制、停复牌、财务数据披露滞后等回测无法完全模拟的因素。

## 九、更新日志

### v2.0（2026-09）

**代码修复（让策略能正常回测交易）：**

1. **修复 `get_fundamentals` 后缺少 `set_index('code')` 的致命 bug**。原代码中 `df.index` 是 `0,1,2,...` 数字序号而非股票代码，导致 `df.index.tolist()` 拿到无效代码、下单静默失败、策略无法交易。现已在所有用到基本面查询的策略（3~9）统一补上 `df.set_index('code')`。
2. **完善股票池过滤逻辑**。新增封装好的 `filter_stocks` 函数，补齐原来缺失的过滤项：
   - ST / *ST（财务风险警示）
   - 退市整理期（名称含"退"）
   - 停牌
   - 次新股（上市不足 N 天，历史数据不足）
   - 当日无行情（`day_open <= 0`）
   - 涨停 / 跌停（涨停买不进、跌停卖不出）
3. 增加**数据不足保护**（如均线策略历史 K 线不足时跳过），避免切片越界报错。

**文档增强（本项目最核心的价值）：**

- 每个函数详解补全三要素：**算法逻辑 + 其他用法 + 所含属性**；
- 基本面 / 技术面概念（PE、PB、ROE、市值、动量、IC/IR、中性化等）全部**面向投资新手**用大白话展开，讲清"是什么、为什么能辅助决策、有什么坑"；
- 每个策略新增「`set_index` 关键步骤」说明，强调这是新手最容易踩的坑。
